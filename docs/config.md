# Configuration reference

Generated by `tools/config_reference.sh` from the code and `tools/config_reference/ranges.tsv`. Do not edit by hand.

Every `@export` field a host can set (352 fields in 52 classes) and every project setting Bustle reads. **Default** is the value of a fresh instance. **Range** comes from the field's editor hint where it has one, and otherwise was checked by hand against the code: *checked* means the class's validation refuses a value outside it, *clamped* means the code clamps the value into it, *warned* means a value out of order with its pair warns once (`validate()`, see [errors.md](errors.md)) and is then used as given, and *unchecked* means the code uses the value as given, so the range is where it makes sense. A dash means the field has no numeric range; its **Effect** says what it takes. The review of each default is in [defaults-review.md](defaults-review.md).

## BustleDirectorRules

`bustle/modules/director/director_rules.gd`

How `BustleDirector` reads tension and paces the story. Tension (0 to 1) is the host's world state, weighted by `tension_inputs`, plus each recently fired event's `BustleEventDef.tension`, fading in a straight line over `memory_minutes`. Above `high`, the story needs relief; below `low`, it needs a raise. Experimental defaults.

| Field | Type | Default | Range | Effect |
| --- | --- | --- | --- | --- |
| `tension_inputs` | `Dictionary[StringName, float]` | `{}` | non-empty input keys; any finite weight; checked | Input key → how much tension each unit of it adds (negative relieves). |
| `memory_minutes` | `int` | `4320` | 1 or more; checked | Game minutes a fired event's tension lasts, fading to nothing. Above 0. |
| `high` | `float` | `0.7` | above low, up to 1; checked | At or above this, the story needs relief. |

## BustleDispositionTable

`bustle/society/disposition_table.gd`

A data table of dispositions between groups, and optionally between two actors. Change a `.tres` value and two actors become hostile, neutral or friendly with no code change. `BustleDispositionPort` reads it. Keys are `"a>b"`: how `a` regards `b`. With `symmetric`, `"b>a"` is used when `"a>b"` is missing. Actor rules win over group rules; anything unlisted gets `default_disposition`. Members of the same group are `same_group` to each other unless a rule says otherwise.

| Field | Type | Default | Range | Effect |
| --- | --- | --- | --- | --- |
| `default_disposition` | `BustleDispositionPort.Disposition` | `Disposition.NEUTRAL` | one of `Disposition.HOSTILE`, `Disposition.NEUTRAL`, `Disposition.FRIENDLY` | For anything no rule covers. |
| `same_group` | `BustleDispositionPort.Disposition` | `Disposition.NEUTRAL` | one of `Disposition.HOSTILE`, `Disposition.NEUTRAL`, `Disposition.FRIENDLY` | Between two members of the same group. |
| `groups` | `Dictionary` | `{}` | — | Group rules: `"group_a>group_b"` to a `BustleDispositionPort.Disposition` value. |
| `actors` | `Dictionary` | `{}` | — | Actor rules: `"actor_a>actor_b"` to a value. They win over group rules. |
| `symmetric` | `bool` | `true` | true or false | True: a missing `"a>b"` falls back to `"b>a"`. |
