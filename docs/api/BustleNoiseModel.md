# BustleNoiseModel

How far a target's noise carries, in metres: the project's movement radius × a surface factor × a gear factor, times the stealth-skill multiplier. It keeps no state; the numbers come from [BustleStealthRules](BustleStealthRules.md).

The numbers.

## Methods

### `compute`

```gdscript
func compute(base_radius: float, surface_factor: float = 1.0, gear_factor: float = 1.0, skill: float = 0.0) -> float
```

The noise radius. `base_radius` comes from how the target moves (for example 1 m still, 7 m walking); `surface_factor` from what it walks on (1.0 is neutral); `gear_factor` from what it wears (1.0 is neutral); `skill` is its stealth skill.

### `event_noise`

```gdscript
static func event_noise(radius: float, position: Vector3 = Vector3(0, 0, 0), source_id: StringName = &"") -> BustleNoiseEvent
```

A one-off sound of `radius` metres at `position`. Stealth skill does not change it.
