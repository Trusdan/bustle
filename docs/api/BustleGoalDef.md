# BustleGoalDef

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

A goal an agent can choose: its band, base weight, preconditions and considerations. Its score is `base_weight × Π consideration`. A goal that uses advertisements makes one candidate per known option, scored as its own score × the option's advertisement score.
