# BustleRomanceRules

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

The lines of the courtship ladder, for [BustleRomance](BustleRomance.md). Opinions are 0 to 100 and compatibility -1 to 1 (see [BustleCompatibility](BustleCompatibility.md)). Each release line sits below its forming line, so a status doesn't flicker. The numbers are experimental defaults.

### `partner_release`

```gdscript

```

A partnership ends (a breakup) when either opinion falls below this. An engagement or marriage never ends on opinion: only the host ends it (`BustleRomance.end()`).

### `affairs_enabled`


Reserved for affairs, off by default. There is no affair path: whatever its value, an agent with a partner or more never starts courting anyone else.

### `history_limit`

### `jealousy_thought`


The timed thought an agent gets when its partner (courting or above) takes to someone else, or null for none (the `BustleRomance.jealous` signal still fires).

### `jealousy_opinion`

```gdscript

```

A partner's opinion of a third agent at or above this makes the agent jealous, once.

### `jealousy_release`

```gdscript

```

Jealousy over that third agent can come again only after the partner's opinion of them has fallen below this.

### `jealousy_opinion_value`

```gdscript

```

Each time jealousy is felt, the jealous agent's opinion of the rival moves by this, as one timed opinion entry (a modest drop). 0: no entry.

### `jealousy_opinion_days`


### `jealousy_verbs`

```gdscript

```

Interactions (by id) that make a partner's partner jealous when done to a third agent (`BustleRomance.notice()`). Empty: none. The host names its own.

## Methods

### `is_valid`

```gdscript
func is_valid() -> bool
```

True when it can be used: opinions from 0 to 100 with each release line below its forming line (jealousy's too), a finite compatibility line, a non-negative finite courting time, a history of at least one entry, and a finite jealousy opinion entry lasting a positive number of days.
