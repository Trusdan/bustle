# BustleLeisure

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Leisure with kinds and tolerance, so agents vary what they do for fun. Each kind (for example a walk, music, games) has a tolerance from 0 to 1. Every use of a kind adds `tolerance_per_use` to it, and tolerances fall by `tolerance_decay_per_day` per game day. `adjust()` scales an option's relief of `need` by `1 − tolerance`, and to 0 at or past `boredom_threshold`, so the scorer stops picking a kind it is bored of and turns to another. An option's kind is its first tag that is one of `kinds`.
The defaults are a starting point, not tuning: a host sets its own.
