# BustleDispositionTable

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

A data table of dispositions between groups, and optionally between two actors. Change a `.tres` value and two actors become hostile, neutral or friendly with no code change. [BustleDispositionPort](BustleDispositionPort.md) reads it.

Keys are `"a>b"`: how `a` regards `b`. With `symmetric`, `"b>a"` is used when `"a>b"` is missing. Actor rules win over group rules; anything unlisted gets `default_disposition`. Members of the same group are `same_group` to each other unless a rule says otherwise.
