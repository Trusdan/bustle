# BustleCombatPort

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Fighting, handed to the host. A host extends this to drive its own combat, and reports progress through `status()` and the result through `outcome()`. The standalone default resolves at once and harmlessly: engaging leaves the fighter RESOLVED, with no damage, no winner and nobody killed.
A fight is a scuffle unless it is engaged as lethal. A host's combat should pass a scuffle's damage through `BustleConflict.filter_damage()`, so a scuffle never kills.

### `engage`


`id` engages `target`, as a scuffle or, with `lethal`, to kill. Ignored when either is empty or they are the same.

### `outcome`

```gdscript
func outcome(id: StringName) -> Dictionary
```

How `id`'s fight ended, once RESOLVED: `{target, lethal, killed}`, where `killed` says whether the target died. Empty before then.

### `status`

```gdscript
func status(id: StringName) -> int
```

Where `id`'s fight stands. NONE for an agent not fighting.
