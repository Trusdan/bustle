# BustleCombatPort

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Fighting, handed to the host. A host extends this to drive its own combat, and reports progress through `status()` and the result through `outcome()`. The standalone default resolves at once and harmlessly: engaging leaves the fighter RESOLVED, with no damage, no winner and nobody killed.
Every fight has an intent: `subdue` (the default) or `kill`. A host's combat should pass a subdue fight's immediate damage through `BustleConflict.filter_damage()`. A target may still die, then or later of its wounds; the host's health system decides, and reports it in `outcome()`.

## Methods

### `engage`

```gdscript
func engage(id: StringName, target: StringName, intent: StringName = &"subdue") -> void
```

`id` engages `target` with `intent` (`subdue` or `kill`). Engaging again changes the intent. Ignored when either id is empty or they are the same.

### `disengage`

```gdscript
func disengage(id: StringName) -> void
```

`id` stops fighting.

### `outcome`

```gdscript
func outcome(id: StringName) -> Dictionary
```

How `id`'s fight ended, once RESOLVED: `{target, intent, killed, downed}`, where `killed` says whether the target died and `downed` whether it was beaten without dying. Empty before then.

### `status`

```gdscript
func status(id: StringName) -> int
```

Where `id`'s fight stands. NONE for an agent not fighting.
