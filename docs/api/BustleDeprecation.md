# BustleDeprecation

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

Inherits: `RefCounted`

Warns when deprecated public API is used: once per symbol per run, with [method @GlobalScope.push_warning]. A deprecated method calls `warn()` first, then keeps working until the next major release removes it (see `docs/public-api/VERSIONING.md`). Nothing else changes: the warning is only a message.

```gdscript
## @deprecated: Use `new_name()` instead.
func old_name() -> void:
BustleDeprecation.warn("BustleExample.old_name", "BustleExample.new_name")
new_name()
```

## Methods

### `warn`

```gdscript

```

Warns that `symbol` (such as `"BustleExample.old_name"`) is deprecated, naming `instead` when there is a replacement. Only the first call for a symbol in a run warns; true when this call did.

### `message`

The warning text for `symbol`, naming `instead` when it isn't empty.

### `reset`
