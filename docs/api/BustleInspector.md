# BustleInspector

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Reads an agent's state for debugging, from what the brain already holds: the scorer's own candidates from the last tick (never recomputed), the last intent, the runner and the order queue. Parts that come from modules not installed yet are marked `{available: false, module: <name>}` instead of being made up. Read-only.

## Methods

### `snapshot`

```gdscript
func snapshot(society: BustleSociety, agent_id: StringName) -> Dictionary
```

Everything worth seeing about agent `agent_id` in `society`: agent, area, autonomy, player control, band, goal, option, order, step, top 3 scores, order queue, needs inputs, and the unavailable parts. `{missing: true}` for an unknown or removed agent.

The `count` best of the last tick's candidates, in the scorer's order (eligible ones first), each with its scores and eligibility.

```gdscript

```

The scorer's breakdown of `goal_id` / `option_id` on the agent's last tick: its scores, eligibility and reasons. `{found: false}` when there was no such candidate.

### `orders`


The agent's order queue, front first: id, forced, and whether it has started.

### `needs`


The needs as far as the brain knows them: no needs module yet, so only the raw `need.*` inputs it was given on its last tick.
