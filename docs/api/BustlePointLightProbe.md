# BustlePointLightProbe

**Experimental:** this API may change before 1.0.

Inherits: `BustleLightProbe`

An ambient level plus point sources. Each enabled source adds `energy × (1 − distance / range)²` inside its range; the total is clamped to 1. An optional `occluded` check lets a project drop a source that something blocks.

### `occluded`

```gdscript
var occluded: Callable
```

Optional: `func(from: Vector3, to: Vector3) -> bool`, true when something blocks the light from a source at `from` to the sample point `to`. Unset: nothing ever blocks.
