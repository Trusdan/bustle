# BustleAffordance

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

One placed smart object: a [BustleAffordanceDef](BustleAffordanceDef.md) at a place, perhaps owned. It advertises to agents (`advertise()`) and is used through reservations: `reserve()` → the host walks the agent there and plays the use → `use()`, which applies the def's need effects (leisure scaled by tolerance), takes payment and releases.
**Capacity:** at most `BustleAffordanceDef.capacity` agents hold it at once; a reservation lapses after `BustleAffordanceDef.hold_minutes`. **Ownership:** an owned affordance scores others at `BustleAffordanceDef.others_mult` (0 refuses them), unless `access_hook` says otherwise. **Cost:** each use costs `cost_hook`'s price (the def's price by default; free to the owner), paid to the owner (or `payee`) through a [BustleTradePort](BustleTradePort.md). **Buying:** when the def names an `BustleAffordanceDef.item`, each use buys it from the owner (or payee) with `BustleTradePort.buy()` instead, offered only while `BustleTradePort.can_buy()` says yes, and `cost_hook` and the def's price don't apply. The owner takes one from its own stock with `BustleTradePort.take()`, without paying, offered only while `BustleTradePort.can_take()` says yes, so every stock change goes through the trade port. A payee doesn't buy from itself. Time is whole game minutes, given by the caller.

### `advertise`

```gdscript

```

The advertisement `agent` sees at minute `now`, `distance` away, or null when it is refused, full, or priced beyond what `trade` says the agent has. Relief and side effects are scaled by `access()`; leisure relief also by `leisure`'s tolerance.

### `use`

```gdscript
func use(agent: StringName, now: int, needs: BustleNeedSet, leisure: BustleLeisure = null, trade: BustleTradePort = null) -> StringName
```

Completes `agent`'s use at minute `now`: pays, lowers the def's relief needs in `needs` (leisure relief scaled by `leisure`'s tolerance, which then rises), raises its side effects, and releases the place. Nothing changes unless it returns `OK`: `REFUSED_ACCESS`, `REFUSED_FULL` (no hold and no room) or `REFUSED_PRICE` (it can't pay, or can't buy the def's item).
