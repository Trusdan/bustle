# BustleDirectorEffects

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Applies a fired event's `BustleEventDef.effects`, in order, to exactly the targets each names ([BustleEventEffect](BustleEventEffect.md)). The host supplies who exists and how to reach them through the callables below; spawns go only through `BustleWorldPort.request_spawn()`. It keeps nothing. Set it as `BustleDirector.effects`.

## Signals

### `applied`

```gdscript
signal applied(event: StringName, kind: StringName, target: StringName, what: StringName, done: bool)
```

One effect was applied: `target` is the agent (or, for a spawn, the area), `what` the thought, order or spawn kind, and `done` whether it took (a mood that took the thought, a brain that queued the order, a host that made the spawn).

## Methods

### `targets`

```gdscript
func targets(effect: BustleEventEffect) -> StringName[]
```

The agents `effect` targets, in id order: those named, those tagged, those in the area. Named agents count only when `agents` lists them (or `agents` is unset).

### `apply`

```gdscript
func apply(def: BustleEventDef, now: int) -> Dictionary[]
```

Applies `def`'s effects as fired at `now`, emitting `applied` for each, and returns them as `{event, kind, target, what, done}` records, in order. An order's id is `<event>.<minute>` for the event's first order effect, and `<event>.<minute>.<index>` (the effect's index in `BustleEventDef.effects`) for each later one, so several order effects in one event can all reach the same agent.
