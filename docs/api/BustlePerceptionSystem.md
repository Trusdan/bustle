# BustlePerceptionSystem

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Node`

Runs a [BustlePerceptionWorld](BustlePerceptionWorld.md) for a scene: [BustlePerceiver](BustlePerceiver.md) and [BustlePerceivable](BustlePerceivable.md) nodes register with it, it copies their state into the world each physics frame, ticks the world and casts the sight rays with physics.

Put one in a scene (or as an autoload). Components find it through the group `GROUP` unless their `system_path` points at one. A ray is blocked by any body on `sight_mask` except the perceiver's and the target's own bodies.
