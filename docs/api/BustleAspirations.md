# BustleAspirations

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

The aspirations module, for one agent: short-lived wants and event-formed fears. It is separate from ambitions, which keep working the same with it on or off.
**Wants.** Each `update()`, an active want whose `BustleWantDef.is_done()` holds is fulfilled: its satisfaction thought goes to the mood. One that has reached its expiry minute instead expires, with no thought. Then, while fewer than `BustleAspirationConfig.auto_wants` automatic wants are active, the eligible want with the highest score is taken (ties to the lower id). The host may also post wants (`post_want()`); all wants together stay within `BustleAspirationConfig.want_cap`.
**Fears.** An event passed to `update()` forms each fear it triggers, or renews one already formed. While formed, a fear multiplies the scores of the goals and options it avoids (`avoidance()`, for `BustleBrain.score_boost`); it only lowers scores. It ends after its duration, or when its clearing fact is true.
Nothing is random: wants and fears come only from causes and state.

## Methods

### `update`

```gdscript
func update(now: int, personality: BustlePersonality = null, inputs: Dictionary = {}, events: StringName[] = [], mood: Object = null) -> void
```

Brings wants and fears up to game minute `now`: fulfils wants whose `BustleWantDef.is_done()` holds in `inputs` (adding their thought to `mood`, anything with `add_thought(def, details)`), expires wants that have run out, ends fears that have run out or are cleared, forms fears from `events`, and fills the automatic want slot from `personality` and `inputs`.

### `choose`

```gdscript
func choose(now: int, personality: BustlePersonality = null, inputs: Dictionary = {}) -> BustleWantDef
```

The eligible want with the highest score (ties to the lower id), or null. Eligible: valid, automatic, every `BustleWantDef.requires` true, not already fulfilled by `inputs`, not active, and past its cooldown. Changes nothing.

### `score_of`

```gdscript
func score_of(def: BustleWantDef, personality: BustlePersonality = null) -> float
```

`def`'s score for `personality`: `Σ weight × (slider − 50) / 100`.

### `post_want`

```gdscript
func post_want(id: StringName, now: int) -> bool
```

Gives the agent want `id` at game minute `now`, posted by the host. False (and no change) for an unknown or invalid want, one already active, or a full cap.

### `fulfill`


Fulfils active want `id` at game minute `now` (the host saying so, or `update()` finding it done): its thought goes to `mood`. False when it isn't active.

### `avoidance`

```gdscript
func avoidance(goal_id: StringName, option_id: StringName = &"") -> float
```

How much the formed fears multiply goal `goal_id`'s score for option `option_id` (for `BustleBrain.score_boost`): the product of `BustleFearDef.avoid_mult` over every fear that avoids the goal, the option, or the option named when it formed. 1 with none. Never above 1. Combine it with other boosts by multiplying.

### `export_state`

```gdscript

```

Active wants, formed fears and when each want last ended, as plain data, with absolute game minutes, so expiry carries over a save.

### `import_state`

```gdscript

```

Restores `export_state()`, replacing everything. False (and nothing changes) when malformed or naming a want or fear the config doesn't have.
