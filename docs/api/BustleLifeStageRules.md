# BustleLifeStageRules

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

The life stages and the calendar they are read with. Ages are game days; `days_per_year` only converts years to days and back, so a host picks its own year length. Use `validate()` before relying on a set: [BustleLifeStages](BustleLifeStages.md) ignores rules that aren't valid.

## Properties

### `days_per_year`

```gdscript
var days_per_year: float = 360.0
```

Game days in one year, for `days_of()` and `years_of()`. Finite and above 0. An experimental default; Bustle assumes no calendar.

### `minutes_per_day`

```gdscript
var minutes_per_day: int = 1440
```

Game minutes in one day, for `BustleLifeStages.advance_to()`. Above 0; 1440 matches the default clock port.

### `stages`

The stages, youngest first.

## Methods

### `validate`

```gdscript
func validate() -> String
```

Why these rules can't be used, or empty when they can: at least one stage; every stage present, with an id used once and finite, not negative `BustleLifeStageDef.min_days` above the stage before it; no empty blocked tag; `days_per_year` finite and above 0; and `minutes_per_day` above 0.
