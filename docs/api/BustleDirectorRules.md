How [BustleDirector](BustleDirector.md) reads tension and paces the story. Tension (0 to 1) is the host's world state, weighted by `tension_inputs`, plus each recently fired event's `BustleEventDef.tension`, fading in a straight line over `memory_minutes`. Above `high`, the story needs relief; below `low`, it needs a raise. Experimental defaults.

## Properties

### `tension_inputs`

```gdscript

```

Input key → how much tension each unit of it adds (negative relieves).

### `memory_minutes`

```gdscript
var memory_minutes: int = 4320
```

Game minutes a fired event's tension lasts, fading to nothing. Above 0.

### `high`

```gdscript
var high: float = 0.7
```

At or above this, the story needs relief.

### `low`

```gdscript
var low: float = 0.3
```

At or below this, the story needs a raise.

### `beat_gap_minutes`

```gdscript
var beat_gap_minutes: int = 0
```

Game minutes after any event fires before the next may. 0: none. It only delays: an event still eligible when the gap ends fires then.

## Methods

### `validate`

```gdscript
func validate() -> String
```

Why these rules can't be used, or empty: a positive memory, 0 <= low < high <= 1, a gap from 0 to the memory, and finite, non-empty tension inputs.
