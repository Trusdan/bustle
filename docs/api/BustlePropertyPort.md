# BustlePropertyPort

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Who owns which things, and where they are. A host extends this to use its own items. The standalone default keeps an in-memory register.
An item is a plain record: `{id, owner_id, place, relieves, protected}`, where `relieves` is need → amount (what having it would ease) and `protected` marks something that can never be taken (a host marks its own: keepsakes, things a story needs). `transfer()` only ever moves an existing item from its owner to someone else; nothing here creates or destroys an item.

## Methods

### `register`

```gdscript
func register(id: StringName, owner_id: StringName, place: StringName, relieves: Dictionary = {}, protected: bool = false) -> bool
```

Registers `id`, owned by `owner_id` at `place`. False (nothing changes) when the id or owner is empty, the id is taken, or `relieves` isn't need → finite amount.

### `transfer`

```gdscript

```

Moves `id` from `from` to `to`. False, changing nothing, when the item is unknown, protected, not owned by `from`, or `to` is empty or `from`.
