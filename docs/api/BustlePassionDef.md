# BustlePassionDef

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

A passion for one skill, as data: how much faster an agent with it learns, which personality sliders make an agent take it up when it has no passion assigned, and an optional thought held while it does that skill's work. [BustleSkills](BustleSkills.md) reads it. The numbers are experimental defaults.

## Properties

### `skill`

```gdscript
var skill: StringName = &""
```

The skill it is a passion for; a [BustleSkillDef](BustleSkillDef.md) with this id must be installed first.

### `learn_mult`

```gdscript
var learn_mult: float = 1.5
```

Practice XP is multiplied by this while the agent has the passion.

### `sliders`

```gdscript
var sliders: Dictionary[StringName, float] = {}
```

Slider → weight, for deriving the passion from personality. Its score is `Σ weight × (slider − 50) / 100`; see `BustleSkills.derived_passions()`. Empty: never derived, only assigned.

### `thought`

```gdscript
var thought: Resource = null
```

A thought (a `BustleThoughtDef` from the needs_mood module, with a duration of 0) held while the agent does this skill's work. Null: none. Without the needs_mood module, leave it null.

## Methods

### `is_valid`

```gdscript
func is_valid() -> bool
```

True when it can be used: a skill id, a positive finite multiplier, and known sliders with finite weights.

### `score`

```gdscript
func score(personality: BustlePersonality) -> float
```

How strongly `personality` matches it: `Σ weight × (slider − 50) / 100`. 0 with no sliders or no personality.
