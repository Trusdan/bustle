# BustleNpcState

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

One agent's state, independent of any scene: who it is, where it is, its brain and its modules' data. A body (a scene node the host makes) can be attached and freed at any time; the state stays in the [BustleSociety](BustleSociety.md).

## Methods

### `body`

```gdscript

```

The attached body, or null when there is none or it has been freed.

### `attach_body`

```gdscript
func attach_body(node: Node3D) -> void
```

Attaches `node` as the body. When a position is known, the body is moved there.

### `detach_body`

```gdscript
func detach_body() -> void
```

Copies the body's position into the state (when it has one) and detaches it.

### `sync_from_body`

```gdscript
func sync_from_body() -> void
```

Copies the attached body's position into the state. Nothing happens without a body.
