# BustleIntent

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

What a [BustleBrain](BustleBrain.md) wants its agent to do after one tick. A body (in the host) applies it. The goal fields say what was chosen and why; the action fields come from the running step's `BustleActionContext.output`, copied only when they have the right type.
