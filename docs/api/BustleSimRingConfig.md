# BustleSimRingConfig

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

How agents are sorted into simulation rings (see [BustleSimRings](BustleSimRings.md)). Every default here is a proposed tunable; projects set their own.

## Properties

### `full_radius`

```gdscript
var full_radius: float = 60.0
```

Outdoors, in the player's area and within this distance of the player (metres): the FULL ring.

### `hysteresis`

```gdscript
var hysteresis: float = 15.0
```

Outdoors, a FULL agent stays FULL until it is farther than `full_radius` plus this (metres).

### `min_dwell_seconds`

```gdscript
var min_dwell_seconds: float = 5.0
```

After a ring change, a change by distance waits this long (real seconds).

### `light_to_offscreen_delay_seconds`

```gdscript
var light_to_offscreen_delay_seconds: float = 10.0
```

A LIGHT agent whose area stops being the player's or a neighbour's goes OFF_SCREEN only after this long (real seconds), so stepping through a door and back doesn't thrash. FULL to OFF_SCREEN by area applies at once.

### `full_whole_interior`

```gdscript
var full_whole_interior: bool = true
```

When the player is in an interior, everyone in it is FULL, wherever they stand.
