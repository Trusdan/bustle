# BustleSimRingConfig

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

How agents are sorted into simulation rings (see [BustleSimRings](BustleSimRings.md)). Every default here is a proposed starting point; projects set their own.

## Properties

### `full_radius`

```gdscript
var full_radius: float = 40.0
```

In the player's area and within this distance of the player (metres): the FULL ring.

### `hysteresis`

```gdscript
var hysteresis: float = 8.0
```

A FULL agent stays FULL until it is farther than `full_radius` plus this (metres).

### `min_dwell_seconds`

```gdscript
var min_dwell_seconds: float = 5.0
```

After a ring change, no further change for this long (real seconds).
