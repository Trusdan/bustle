The numbers behind [BustleConflict](BustleConflict.md): who fights, how far help is looked for, how rarely a fight turns lethal, and how quarrels turn into scuffles.

## Properties

### `fight_threshold`

```gdscript
var fight_threshold: float = 60.0
```

The average of an agent's boldness and temper (0 to 100) at or above which it fights a threat. Below it, it fetches help when an ally is near, and flees otherwise.

### `help_radius`

```gdscript
var help_radius: float = 15.0
```

How far away, in metres, an ally can be and still be fetched.

### `flee_distance`

```gdscript
var flee_distance: float = 10.0
```

How far, in metres, a fleeing agent runs before it feels safe.

### `lethal_chance`

```gdscript
var lethal_chance: float = 0.02
```

The chance (0 to 1) that a fight is lethal rather than a scuffle. Rare by default.

### `scuffle_floor`

```gdscript
var scuffle_floor: float = 1.0
```

The health a scuffle always leaves its victim (see `BustleConflict.filter_damage()`).

### `quarrel_chance`

```gdscript
var quarrel_chance: float = 0.3
```

The chance (0 to 1) that a quarrel becomes a scuffle, at temper 100; it scales with temper.
