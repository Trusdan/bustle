# BustleConverseAction

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `BustleActionHandler`

`converse`: a [BustleConversation](BustleConversation.md) one turn per tick, for agents in view. The partner is `params.with`, or the step's option id when that's empty (as when a goal picks someone to talk to from advertisements, like the comfort hook's). `params.opener` names the first turn's interaction. A turn happens on the first tick at or after its minute, so the results match `BustleConversation.run()` for the same start.
It fails with `no_partner`, `turned_away` (the partner won't talk now, `BustleConversation.accepts`), `declined` (the roll to start failed) or `nothing_to_say`. While it runs, the output names the partner as `talk_to`, and each turn's result is in it as `turn`. The conversation's state is plain data in the step's data, so it saves with the runner.
