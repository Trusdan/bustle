# BustleScheduleRoster

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Every agent's [BustleSchedule](BustleSchedule.md), chosen by job. An agent's job is the first role it holds (in the roles port's sorted order) that [BustleRoleSchedules](BustleRoleSchedules.md) has a routine for; it follows that routine, or its own (`set_own()`) when it has no job. When a role's holder changes, the old and new holders' routines swap at once (`schedule_changed`); attendance and owed wages stay with the agent. `settle()` pays every agent's ended shifts through the trade port.
