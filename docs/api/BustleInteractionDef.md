# BustleInteractionDef

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

One kind of interaction between two agents, as data (a greeting, a chat, kind words, a slight, an insult): how much it moves each side's opinion of the other, for how long, how much the pair's compatibility and each side's mood bend that, and the thoughts it leaves. See `BustleSocialInteractions.outcome()`.

### `spread`

```gdscript

```

Up to this much is added or taken away at random (seeded per pair, minute and interaction).

### `compatibility_scale`

```gdscript
var compatibility_scale: float = 0.5
```

How much compatibility bends the values, like mood: a compatible pair gains more and loses less, an incompatible pair the reverse. A gain is multiplied by `1 + compatibility × compatibility_scale`, a loss by `1 − compatibility × compatibility_scale` (never below 0).

### `mood_scale`

```gdscript
var mood_scale: float = 0.3
```

How much each side's mood bends its own value: a good mood (above 50) makes gains larger and losses smaller, a low mood the reverse, by up to this share at the ends of the scale.

### `weight`


How often a conversation picks it, before sliders, traits, opinion and mood. 0: only ever as a conversation's opener (see [BustleConversation](BustleConversation.md)).

### `slider_weights`

```gdscript
var slider_weights: Dictionary[StringName, float] = {}
```

Personality slider → how strongly it bends `weight`: the weight is multiplied by `1 + w × (slider − 50) / 50` (never below 0), so a high slider makes it likelier for a positive `w`. Keys are `BustlePersonality.SLIDERS` names.
