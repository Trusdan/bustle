# BustleCrimeWatch

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

What becomes of each theft: who perceived it, who it's reported to, and the deed it leaves when nobody did. Every `BustleCrime.theft` becomes a record, and every record is either witnessed or a deed (an open trace that its owner finds later, and that the stolen goods themselves point to). Each witness, and an owner who finds a deed, remembers it and then decides what to do about it: one of `BustleWitnessJudge.OUTCOMES` (`should_report`).
There are no made-up witnesses: an agent witnesses a theft only when `perceives` says it perceived it. By default that's every other agent in the place who isn't incapacitated (the health port). The thief's own judgement (`BustleCrime.is_observed`) can be wrong when the host gives it one, for example an onlooker the thief didn't notice, so a theft can have witnesses. With both defaults, a thief only steals where nobody can perceive it, so every theft is a deed.
Reports go to a role (`authority_role`), never to a named agent: the host decides who holds it (the roles port) and what follows. A report is made at once. Confronting, telling the victim and gossiping are only events: a confrontation is words, never a fight or an intent to harm. Nothing here punishes, fines or harms anyone.

## Signals

### `witnessed`

```gdscript
signal witnessed(witness: StringName, thief: StringName, item: StringName, record: Dictionary)
```

`witness` perceived `thief` taking `item`. `record`: see `record()`.

### `crime_reported`

```gdscript
signal crime_reported(reporter: StringName, role: StringName, report: Dictionary)
```

`reporter` reported a theft to `role`. `report`: the record as the reporter knows it, plus `reporter`, `role`, `authority` (the role's holder then, maybe empty) and `reported_at`. The thief is empty when the reporter doesn't know who it was.

### `deed_found`

```gdscript
signal deed_found(finder: StringName, item: StringName, record: Dictionary)
```

`finder`, the owner, found `item` gone: a deed came to light.

### `decided`

```gdscript
signal decided(agent: StringName, outcome: StringName, record: Dictionary)
```

`agent` decided `outcome` (one of `BustleWitnessJudge.OUTCOMES`) about a record it knows of.

### `confronted`

```gdscript
signal confronted(witness: StringName, thief: StringName, record: Dictionary)
```

`witness` accused `thief` to its face. Words only.

### `victim_told`

```gdscript
signal victim_told(witness: StringName, owner_id: StringName, record: Dictionary)
```

`witness` told `owner_id` what it saw.

### `gossiped`

```gdscript
signal gossiped(teller: StringName, listener: StringName, record: Dictionary)
```

`teller` told `listener` about the theft.

### `perceives`

```gdscript

```

(agent, thief, place) → true when `agent` perceived `thief` stealing at `place`. Empty: any agent in that place who isn't incapacitated.

### `memory_of`

```gdscript
var memory_of: Callable = Callable()
```

(id) → that agent's [BustleMemory](BustleMemory.md), or null. Witnesses note the thief and the item there; an owner who finds a deed notes the item where it was taken.

### `judge`

```gdscript
var judge: BustleWitnessJudge
```

The default decision.

### `should_report`

```gdscript
var should_report: Callable = Callable()
```

(agent, case) → one of `BustleWitnessJudge.OUTCOMES`. Empty: `judge`. The case is `{record, thief, owner_id, place, can_confront, gossip_to}`; a thief the agent doesn't know is empty. Anything else means silent.

### `can_reach`

```gdscript
var can_reach: Callable = Callable()
```

(agent, other) → true when `agent` can reach `other` now. Empty: both are agents in the same area.

### `gossip_to`

```gdscript
var gossip_to: Callable = Callable()
```

(agent, record) → who `agent` would gossip to, or empty (then it can't). Empty: nobody.

## Methods

### `record`

```gdscript
func record(id: int) -> Dictionary
```

Record `id` (a copy): `{id, thief, owner_id, item, place, at, witnesses, known_by,
decisions, reporters, deed, found_at}`. `deed` is true when nobody witnessed it; `decisions` is agent → outcome; `found_at` is the minute its owner found it, or -1. Empty when unknown.

### `records`


Every record, by id.

### `open_deeds`

```gdscript
func open_deeds() -> Dictionary[]
```

The deeds nobody has found yet, by id: the traces the host's law can follow.

### `known_by`

```gdscript
func known_by(agent: StringName) -> int[]
```

The ids of the records `agent` knows about (witnessed, or found its own loss), by id.

### `question`

```gdscript
func question(agent: StringName, now: int) -> Dictionary[]
```

What `agent` can tell when questioned at minute `now`, by record id: `{id, item, owner_id, place, at, thief, outcome}`. The thief is named only when the agent witnessed it and still remembers the thief (`memory_of`; without a memory, it does). Silent witnesses can be questioned too.

### `stolen_goods_of`

```gdscript
func stolen_goods_of(agent: StringName) -> Dictionary[]
```

The stolen goods `agent` still owns, as records by id: evidence the host can find on it.

### `notice_losses`

```gdscript
func notice_losses(owner_id: StringName, place: StringName, now: int) -> int[]
```

`owner_id`, at `place` at minute `now`, finds what was stolen from it there and nobody saw go: each such deed is found, the owner knows of it and remembers the item there, `deed_found` is emitted, and the owner decides what to do (not knowing the thief). Returns the record ids found.
