# BustleCrimeWatch

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

What becomes of each theft: who perceived it, who it's reported to, and the deed it leaves when nobody did. Every `BustleCrime.theft` becomes a record, and every record is either witnessed (each witness remembers it and reports it) or a deed (an open trace that its owner finds later, and that the stolen goods themselves point to).
There are no made-up witnesses: an agent witnesses a theft only when `perceives` says it perceived it. By default that's every other agent in the place who isn't incapacitated (the health port). The thief's own judgement (`BustleCrime.is_observed`) can be wrong when the host gives it one, for example an onlooker the thief didn't notice, so a theft can have witnesses. With both defaults, a thief only steals where nobody can perceive it, so every theft is a deed.
Reports go to a role (`authority_role`), never to a named agent: the host decides who holds it (the roles port) and what follows. Nothing here punishes, fines or harms anyone.

## Signals

### `witnessed`

```gdscript
signal witnessed(witness: StringName, thief: StringName, item: StringName, record: Dictionary)
```

`witness` perceived `thief` taking `item`. `record`: see `record()`.

### `crime_reported`

```gdscript
signal crime_reported(reporter: StringName, role: StringName, report: Dictionary)
```

`reporter` reported a theft to `role`. `report`: the record as the reporter knows it, plus `reporter`, `role`, `authority` (the role's holder then, maybe empty) and `reported_at`. The thief is empty when the reporter doesn't know who it was.

### `deed_found`

```gdscript
signal deed_found(finder: StringName, item: StringName, record: Dictionary)
```

`finder`, the owner, found `item` gone: a deed came to light.

## Methods

### `record`

```gdscript
func record(id: int) -> Dictionary
```

Record `id` (a copy): `{id, thief, owner_id, item, place, at, witnesses, known_by,
reporters, deed, found_at}`. `deed` is true when nobody witnessed it; `found_at` is the minute its owner found it, or -1. Empty when unknown.

### `notice_losses`

```gdscript
func notice_losses(owner_id: StringName, place: StringName, now: int) -> int[]
```

`owner_id`, at `place` at minute `now`, finds what was stolen from it there and nobody saw go: each such deed is found, the owner knows of it, `deed_found` is emitted and the owner reports it (not knowing the thief). Returns the record ids found.
