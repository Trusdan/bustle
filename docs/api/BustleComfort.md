# BustleComfort

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

The comfort hook: an agent who notices a friend in a low mood is offered comforting them. For each such friend it adds an advertisement to the agent's [BustleSenses](BustleSenses.md) (option id: the friend; relief: `need`, larger the lower the friend's mood; tags: `tags`) and sets the `need.<need>` input to 1, so a goal with `BustleGoalDef.uses_advertisements` can pick whom to comfort and a `converse` step with a comfort opener can do it.
How much an agent cares is its need weight, `need.<need>.weight` in its [BustleModifierSet](BustleModifierSet.md), which the brain reads for every advertised need: a trait raises or lowers it with `BustleTraitDef.mults`. Nothing here depends on the mood module: a mood is anything with a `mood` number.

## Methods

### `urgency`

```gdscript
func urgency(mood: float) -> float
```

How much comfort an agent in `mood` needs: 0 at or above `low_mood`, up to 1 at mood 0 (and 0 for no mood).

### `advertise`

```gdscript
func advertise(agent_id: StringName, noticed: StringName[], social: BustleSocialPort, mood_of: Callable, senses: BustleSenses) -> int
```

Adds an advertisement to `senses` for each agent in `noticed` that `agent_id` counts as a friend in `social` and whose mood (`mood_of`, (id) → anything with a `mood`, or null) is low. Returns how many it added.
