# BustleWorldPort

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Where agents and places are, how areas connect, and how bodies are made. A host extends this and overrides every method. The standalone default is one area, `DEFAULT_AREA`, with everyone in it, places at positions set with `set_place()` (the origin for any other), no travel time, and **no bodies**: it never spawns, frees or moves anything, so it is headless only.
