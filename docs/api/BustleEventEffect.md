# BustleEventEffect

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

One thing a fired [BustleEventDef](BustleEventDef.md) does, as host data, applied by [BustleDirectorEffects](BustleDirectorEffects.md): 
- `THOUGHT`: gives `thought` to each target; 
- `ORDER`: orders each target to run `sequence` (at `place`, if set); 
- `SPAWN`: asks the world port to bring `count` of `spawn_kind` into `spawn_area`. The host makes them, or not; Bustle creates nothing. 
Targets are the agents in `target_ids`, plus those with `target_tag`, plus everyone in `target_area`. Nobody else is touched.
