How a [BustleMemory](BustleMemory.md) holds and forgets, as data. Each kind of memory fades on its own half-life in game hours; each source starts at its own strength. An entry is forgotten once its strength falls below `forget_below`. These are starting numbers, not tuning: a host sets its own.

## Properties


The most entries one agent keeps; past it, the weakest goes.

### `forget_below`
