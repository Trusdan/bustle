# BustleStuckWatch

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Tells a stuck agent from one in a legitimate long activity, from one observation per agent per step. A host, a soak or a bench feeds it: `observe()` takes what the caller saw, and `observe_agent()` reads what it can from a [BustleNpcState](BustleNpcState.md) and asks the hooks for the rest. It only reads; it never changes an agent, and it makes no random rolls.
**Legitimate long activity** (never stuck): sleep, attending a schedule block that hasn't ended (including being away for it), travel still closing on its destination (`travel_hook`), an order or other lock in force, a mental state inside its duration, waiting on or using an affordance, and off-screen catch-up still advancing `BustleNpcState.last_update_minute` (unless `check_offscreen_progress`). The caller decides the rest and passes `legit`.
**Stuck**: more than `bound_minutes` in a row with no legitimate activity and no progress (same goal and step, nothing consumed, and the position within `move_epsilon` of where the run began, or for an off-screen agent the same place with no hop pending). Also stuck, whatever the goal: the same goal failing `fail_loop` steps in a row, or a mental state still active past its end.

## Properties

### `bound_minutes`

```gdscript
var bound_minutes: int = 120
```

Game minutes without progress before an agent counts as stuck.

### `move_epsilon`

```gdscript
var move_epsilon: float = 0.5
```

How far an agent must move (metres) to count as progress.

### `fail_loop`

```gdscript
var fail_loop: int = 3
```

Failed steps of the same goal in a row that count as a failure loop.

### `ring_config`

```gdscript
var ring_config: BustleSimRingConfig = <unknown>
```

The ring settings `observe_agent()` reads the off-screen interval from (`BustleSimRingConfig.offscreen_interval_game_minutes`). Set it to the rings' own `BustleSimRings.config` so a change there applies here too.

### `check_offscreen_progress`

```gdscript
var check_offscreen_progress: bool = false
```

When false (the default), off-screen catch-up that is still advancing counts as legitimate, as for any long activity. When true, it doesn't: an OFF_SCREEN agent seen through `observe_agent()` has to show progress like any other (a new goal or step, a new place, a hop pending, something consumed, or `offscreen_progress_hook`), so an agent the rings keep up to date but that never gets anywhere is found.

### `travel_hook`

```gdscript
var travel_hook: Callable = Callable()
```

`func(agent: StringName, now: int) -> bool`: true while `agent`'s travel is still closing on its destination (its remaining path or time is going down), which is legitimate. Asked by `observe_agent()`. Empty: no travel counts.

### `offscreen_progress_hook`

```gdscript
var offscreen_progress_hook: Callable = Callable()
```

`func(agent: StringName, now: int) -> bool`: true when the host's own off-screen simulation moved OFF_SCREEN `agent` on since the last observation (a hop made, a task advanced), which is progress. Asked by `observe_agent()` for OFF_SCREEN agents only. Empty: only what the agent's state shows counts.

## Methods

### `observe`

```gdscript
func observe(agent: StringName, now: int, minutes: int, seen: Dictionary) -> Dictionary
```

Notes what `agent` did over the `minutes` ending at game minute `now`. `seen` holds `goal` and `step` (what it's doing), `legit` (in a legitimate long activity), `consumed` (something met a need), `progress` (other progress the caller saw), `position` (Vector3) or `place` (StringName, off-screen), `hop_pending`, `failed` (its goal failed this step) and `state_overdue` (a mental state past its end); any may be left out. Returns a change to report: empty, or `{event: "stuck", reason, since}` or `{event: "unstuck", reason, minutes}`.

### `observe_agent`

```gdscript
func observe_agent(state: BustleNpcState, now: int, minutes: int, seen: Dictionary = {}) -> Dictionary
```

`observe()` for `state`, filling in what the state shows: the goal and step from its brain, a failure only when the brain thought again (so watching more often than it thinks doesn't count one failure twice), and its position (FULL or LIGHT, when known) or its area (OFF_SCREEN). `travel_hook` can make it legitimate. For an OFF_SCREEN agent, catch-up still advancing within `ring_config`'s off-screen interval is legitimate unless `check_offscreen_progress`, and `offscreen_progress_hook` can report progress. Anything in `seen` (the keys `observe()` takes) is used as given, and `legit` or `progress` there adds to what the watch finds. Refuses a null `state`: it warns once and returns an empty change.

### `is_stuck`

```gdscript
func is_stuck(agent: StringName) -> bool
```

True while `agent` is stuck.

### `longest_still`

```gdscript
func longest_still(agent: StringName) -> int
```

### `spells`
