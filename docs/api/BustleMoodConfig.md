How mood moves, as data. Mood runs from `min_mood` to `max_mood`; it heads for its target (the baseline plus every active thought) at `rise_per_hour` when below it and `fall_per_hour` when above, both times `volatility`. These are starting numbers, not tuning: a host sets its own. Per agent, the modifiers `mood.baseline`, `mood.volatility`, `mood.rise.mult` and `mood.fall.mult` adjust them.
