# BustleHealthBehaviour

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

The health behaviour: agents react to the host's health. The host owns bodies, harm, illness and treatment and reports them through [BustleHealthPort](BustleHealthPort.md); this reads the port each tick and keeps nothing of its own, so no wound, illness or body state lives in Bustle.
`tick()` (or its three parts) for each agent: 
- `apply()`: capacities below full scale modifier keys by `BustleHealthConfig.effects` (`work.speed`, `move.speed`, and `capacity.<name>`), under source `SOURCE`. At full health nothing is written. 
- `sync()`: holds the pain thought for the current pain and a tag thought for each visible tag, and drops the rest, so they clear when the port does. 
- `fill_inputs()`: `health.pain`, `health.needs_care`, `fact.downed` and `fact.contagious`, set only while non-zero.
A downed agent (`BustleHealthPort.is_incapacitated()`) chooses no work and doesn't travel: set `BustleBrain.gate` to `allows()`. With the default port everyone is healthy and a tick does nothing. Nothing is random: the same readings give the same results.

### `apply`

```gdscript
func apply(id: StringName, modifiers: BustleModifierSet) -> void
```

Applies `id`'s capacities to `modifiers`: it removes what `SOURCE` wrote before, then writes `capacity.<name>` and each effect's key for capacities below full (effects on one key multiply). Nothing is written at full health.

### `chosen`

```gdscript
func chosen(id: StringName) -> BustleHealthThought[]
```

The thought rules `id` meets now: the pain rule with the highest line its pain reaches, then each tag rule whose tag it shows, in rule order.

### `sync`

```gdscript
func sync(id: StringName, mood: Object = null) -> StringName[]
```

Brings `id`'s health thoughts in line with the port on `mood` (anything with `set_held(def, held, details)`, such as a `BustleMood`; optional): it drops every rule thought not chosen, then holds the chosen ones with `pain` or `tag` in their reason. Returns the chosen thought ids, in rule order.

### `fill_inputs`

```gdscript
func fill_inputs(id: StringName, inputs: Dictionary[StringName, float]) -> void
```

Sets `id`'s health inputs in `inputs`, each only while non-zero, and erases them otherwise: `INPUT_PAIN`, `INPUT_CARE`, `INPUT_DOWNED` and `INPUT_CONTAGIOUS`.

### `tick`

```gdscript
func tick(id: StringName, modifiers: BustleModifierSet, mood: Object = null, inputs: Variant = null) -> void
```

One tick for `id`: `apply()` on `modifiers`, `sync()` on `mood` and `fill_inputs()` on `inputs` (each skipped when null).

### `illness_began`

```gdscript
func illness_began(id: StringName, tag: StringName, mood: Object) -> bool
```

A host event: `id` fell ill with `tag` (for example `sick`). Holds that tag's thoughts on `mood` at once, without waiting for the next `sync()`. True when a rule has the tag. The next `sync()` follows the port's `BustleHealthPort.visible_tags()` again, so the port stays the truth.

### `recovered`

```gdscript
func recovered(id: StringName, mood: Object) -> void
```

A host event: `id` recovered. Drops every tag thought from `mood` at once.

### `allows`

```gdscript
func allows(id: StringName, goal_tags: StringName[], option_tags: StringName[]) -> bool
```

The gate for `BustleBrain.gate`: false while `id` is downed and the goal (`goal_tags`: its id and tags) or option (`option_tags`) carries any of `BustleHealthConfig.downed_blocks`. True otherwise.
