# BustleCareerRank

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

One rank of a career track, as data: its id, the wage a career block earns at it, the skill level an agent needs to hold it, and how it is reviewed. [BustleCareerDef](BustleCareerDef.md) lists them lowest first. The review numbers are experimental defaults.

## Properties

### `id`

```gdscript
var id: StringName = &""
```

Its id, unique in its track.

### `wage`

```gdscript
var wage: int = 0
```

What attending one career block earns at this rank, in the trade port's unit, paid at the block's end like any schedule wage. It replaces the block's own wage.

### `min_skill`

```gdscript
var min_skill: float = 0.0
```

The least level in the track's skill (read through the skill port) an agent needs to hold it. 0: none.

### `review_days`

```gdscript
var review_days: int = 7
```

Working days (days with a career block) at this rank in each review window (see `BustleCareers.update()`). Days off don't count.

### `promote_if`

```gdscript
var promote_if: float = 0.75
```

A window's performance (0 to 1) at or above this makes a promotion due.

### `demote_if`

```gdscript
var demote_if: float = 0.35
```

A window's performance at or below this makes a demotion due.

## Methods

### `is_valid`

```gdscript
func is_valid() -> bool
```

True when it can be used: an id, a wage of at least 0, a finite, non-negative skill minimum, a review window of at least one day, and finite thresholds with `demote_if` below `promote_if`.
