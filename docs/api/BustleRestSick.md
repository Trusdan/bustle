# BustleRestSick

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

The rest-when-sick goal, opt-in: an agent who is ill rests instead of working or running errands until the health port says it is better. Bustle names where to rest; the host moves the body and owns the illness and the recovery. Bustle keeps no illness state: every answer comes from the ports each time.
**Who rests:** an agent the port shows one of `sick_tags` for (`BustleHealthPort.visible_tags()`), or one of whose capacities is below its line in `capacity_lines` (`BustleHealthPort.capacity()`), unless it is downed (`BustleHealthBehaviour.is_downed()`), locked (`is_locked`), or should seek care first (`seek_care`). `fill_inputs()` sets its `INPUT` to `sickness()`.
**Its place:** `BAND`, above duty and below orders: it outranks ordinary work and errands, never an order, a lock or an urgent need. Orders aren't gated.
**Where:** `bed_for()`: the agent's own item (`BustlePropertyPort.items_of()`) that relieves `bed_need`, at a place the world port knows; else where it stands.
**Ending:** the [BustleRestSickAction](BustleRestSickAction.md) rests while the agent is still ill, and is done on the first tick after the port clears the tag or restores the capacity.
Register a [BustleRestSickAction](BustleRestSickAction.md) for `ACTION` on each agent's runner. Nothing is random.
