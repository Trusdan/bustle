# BustleLock

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

A host's pin on one agent: a place to stay at, a goal (or sequence) to run, or both, under a `lock_id`. `BustleSociety.lock()` holds it; while any lock is held the agent is locked (`BustleSociety.is_locked()`). A lock is just a lock: what it's for is the host's.
