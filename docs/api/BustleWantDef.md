# BustleWantDef

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

One short-lived want, as data: who it suits (personality and circumstances), when it's fulfilled, how long it lasts and the thought fulfilling it gives. [BustleAspirations](BustleAspirations.md) reads it. Every circumstance, progress input and fact is a name the host fills each update. Bustle ships none.
