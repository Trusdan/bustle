# BustleSocialPort

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

How agents feel about each other and what they know of each other's deeds. A host (or a bridge to a social engine) extends this and overrides every method. The standalone default has no opinions or relationship kinds, and keeps a small in-memory list of deeds: the actor and the named witnesses know a deed first-hand, and `share_news()` passes only first-hand deeds, one hop, so nothing spreads further on its own.

### `record_deed`

```gdscript
func record_deed(actor: StringName, verb: StringName, target: StringName, place: StringName, witnesses: Dictionary[], _magnitude: float = 1.0, _return_magnitude: float = 0.0) -> StringName
```

Records that `actor` did `verb` to `target` at `place`, seen by `witnesses` (each a dictionary with an `id`; entries without one are ignored). `magnitude` is how much the deed moved the target (an interaction passes its outcome for the recipient), and `return_magnitude` how much it moved the actor (the outcome for the initiator). A port that weighs deeds itself can use them; the default and the built-in store keep neither. Returns the deed's key, or empty when the actor or verb is empty.

### `knows`

True when `agent` knows the deed `key`. Unknown keys: false.

### `share_news`

```gdscript
func share_news(teller: StringName, listener: StringName, _place: StringName) -> int
```

`teller` tells `listener` the deeds the teller knows first-hand and the listener doesn't know yet. Returns how many. The listener knows them second-hand, so can't pass them on. The default ignores `_place`.
