# BustleBands

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

The priority bands goals sit in. A band is a whole number and the higher one wins: the scorer chooses only from the highest band that has an eligible candidate, and scores are never compared across bands. The gaps leave room for bands that later features add between these.
