What the health behaviour does with the host's readings: the capacity effects on modifiers, the thoughts, and what a downed agent may not choose. `defaults()` gives experimental values.

## Properties

The capacity → modifier effects. Every capacity named here also writes `capacity.<name>` (base 1) as its clamped amount.

While downed (`BustleHealthPort.is_incapacitated()`), a goal whose id or tags, or an option whose advertisement tags, include any of these is not chosen.

## Methods

### `defaults`

```gdscript
static func defaults() -> BustleHealthConfig
```

Experimental defaults: 
- `moving` scales `move.speed`, `manipulation` scales `work.speed`, and `consciousness` scales both, each in a straight line to 0 at no capacity; 
- pain of 0.2 or more holds `in_pain` (−6), and of 0.6 or more `in_great_pain` (−14) instead; 
- the `sick` tag holds `feeling_sick` (−8).
