# BustleHealthConfig

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

Inherits: `Resource`

What the health behaviour does with the host's readings: the capacity effects on modifiers, the thoughts, and what a downed agent may not choose. A new resource starts empty: no effects and no thoughts, so health changes nothing until the host adds some. `defaults()` gives Bustle's default config, which [BustleHealthBehaviour](BustleHealthBehaviour.md) uses when it is given none.

## Methods

### `defaults`

```gdscript
static func defaults() -> BustleHealthConfig
```

The config [BustleHealthBehaviour](BustleHealthBehaviour.md) uses when it is given none: 
- `moving` scales `move.speed`, `manipulation` scales `work.speed`, and `consciousness` scales both, each in a straight line to 0 at no capacity; 
- pain of 0.2 or more holds `in_pain` (−6), and of 0.6 or more `in_great_pain` (−14) instead; 
- the `sick` tag holds `feeling_sick` (−8), and the `fever` tag `feverish` (−6).

### `validate`

Why it can't be used, or empty: an invalid or missing effect or thought rule, or an empty downed block.
