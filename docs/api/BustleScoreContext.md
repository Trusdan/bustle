What the scorer knows about one agent at one moment: its input values, the options it knows of, its need weights and tag multipliers, and how to check preconditions it doesn't know itself.

### `score_boost`

```gdscript

```

`func(goal_id: StringName, option_id: StringName) -> float`: a multiplier on that candidate's score (for example a long-term aim favouring some goals). It never changes a band. Unset: 1.

### `precondition_check`


`func(goal_id: StringName, precondition: Dictionary) -> bool` for precondition kinds other than `input`. Unset: such preconditions fail.
