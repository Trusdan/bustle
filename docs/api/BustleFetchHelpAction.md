# BustleFetchHelpAction

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

Inherits: `BustleActionHandler`

`fetch_help`: goes to the ally `BustleConflict.notice()` picked (`move_to` and `talk_to` in the output) and, once within `REACH` metres (or at once without positions), hands the threat to it with `BustleConflict.call_help()`. When there's no ally or the ally can't come (it has a conflict of its own), it switches to fleeing (`BustleConflict.switch_to_flee()`) and the `flee` goal takes over. Done either way.

### `approach`

```gdscript
static func approach(context: BustleActionContext, here: Variant, there: Variant, helper: StringName) -> bool
```

The fetch-help movement and arrival rule, shared by every errand that goes to fetch someone: while the agent at `here` is more than `REACH` metres from `helper` at `there`, it asks the host to move it there (`move_to` and `talk_to` in `context`'s output) and returns true. Once within reach, or at once when either position is unknown (not a `Vector3`), it returns false: the agent has arrived.
