# BustleFetchHelpAction

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `BustleActionHandler`

`fetch_help`: goes to the ally `BustleConflict.notice()` picked (`move_to` and `talk_to` in the output) and, once within `REACH` metres (or at once without positions), hands the threat to it with `BustleConflict.call_help()`. When the ally can't come, it flees instead. Done when the agent is out of the conflict.
