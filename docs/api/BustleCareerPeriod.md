# BustleCareerPeriod

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

How a rank is reviewed in one host-defined period, as data: a full set of review rules that replaces the rank's own while a review window is judged in that period (see `BustleCareerRank.periods` and `BustleCareers.update_in_period()`). Bustle defines no periods and assumes no calendar: a period is any id the host chooses, such as a season, a busy month or a quiet spell.

## Properties

### `review_days`

```gdscript
var review_days: int = 7
```

Working days (days with a career block) in each review window in this period.

### `promote_if`

```gdscript
var promote_if: float = 0.75
```

A window's performance (0 to 1) at or above this makes a promotion due in this period.

### `demote_if`

```gdscript
var demote_if: float = 0.35
```

A window's performance at or below this makes a demotion due in this period.

## Methods

### `is_valid`

```gdscript
func is_valid() -> bool
```

True when it can be used, by the same rules as a rank's own: a review window of at least one day, and finite thresholds with `demote_if` below `promote_if`.
