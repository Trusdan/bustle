# BustleRestSickAction

**Experimental:** this API may change before 1.0.

Inherits: `BustleActionHandler`

`rest_sick`: the agent rests while it is ill (`BustleRestSick.wants_rest()`). With a bed (`BustleRestSick.bed_for()`) it first asks the host to move it there (`move_to` in the output); then, or at once without one, it rests, naming the bed in the output (`rest_sick`: the bed's item, or empty where it stands). Bustle names where; the host moves the body and plays the rest. Done on the first tick it no longer should rest: the port cleared the tag or restored the capacity (or it is now downed, locked, or seeking care first).
