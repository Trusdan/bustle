Text commands for inspecting and steering a [BustleSociety](BustleSociety.md) while developing. `run()` takes one line and returns the answer as text. It does nothing in release builds (see [BustleDebug](BustleDebug.md)).

- `help`, `agents` - `why <agent> [goal] [option]`: the last tick's top candidates, or one candidate's score breakdown, straight from the scorer. - `need <agent>`: the need inputs the agent was last given. There is no needs module yet, so needs can't be set here. - `order <agent>` lists the queue; `order <agent> <sequence> [forced]` queues one of `sequences`; `order <agent> cancel <order_id>` cancels one.
