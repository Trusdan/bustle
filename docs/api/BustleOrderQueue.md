# BustleOrderQueue

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

One agent's orders, first in, first out, with the runner for the front one. A [BustleBrain](BustleBrain.md) owns it and decides each tick whether the front order runs.

- **Submitting** checks the order and refuses it, with a reason, when its id is empty or already queued, it has no sequence, or a step's action has no handler. A refused order is reported IMPOSSIBLE and never queued. - **Running:** only the front order runs. When something outranks it, `pause()` interrupts it and it stays at the front; when it runs again its step starts again. - **Finishing:** every order ends once, reported with `finished` and kept for `take_results()`: DONE, FAILED (with the step's reason) or CANCELLED. Cancelling a queued order removes it before it ever starts; cancelling the running one cleans its step up once.
