# BustleMemory

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

One agent's memory of where people, places and items are. Each entry is one subject of one kind (`PERSON`, `PLACE`, `ITEM`) with an area, maybe a position, its source (`SAW`, `HEARD`, `TOLD`, `ROUTINE`) and a strength that halves every half-life of its kind ([BustleMemoryConfig](BustleMemoryConfig.md)). An entry is forgotten when its strength falls below the config's threshold, and past capacity the weakest entry goes.
A new note about a subject replaces the old one when it is at least as strong as what is left of the old one, so a fresh sighting beats an old rumour but a rumour doesn't overwrite a fresh sighting. Time is whole game minutes.

## Methods

### `note`

```gdscript
func note(kind: StringName, subject: StringName, area: StringName, position: Variant, source: StringName, now: int) -> bool
```

Notes where `subject` (of `kind`) is, at minute `now`: `area` and `position` (null when unknown), from `source`. Returns true when it was kept (see the class description); false for an empty subject, an unknown source, a weaker note, or a note so weak that a full memory dropped it straight away.

### `recall`

```gdscript
func recall(kind: StringName, subject: StringName, now: int) -> Dictionary
```

What is remembered about `subject` at minute `now`, with its current strength: `{kind, subject, area, position, source, strength, at}`; empty when nothing is (or it has faded below the threshold, in which case it is forgotten).

### `confidence`

```gdscript
func confidence(kind: StringName, subject: StringName, now: int) -> float
```

How sure the agent is of `subject`'s whereabouts at minute `now`, from 0 to 1.

### `forget`

```gdscript
func forget(now: int) -> void
```

Drops every entry that has faded below the threshold by minute `now`.

### `size`

```gdscript
func size() -> int
```

The number of entries held (some may have faded since; see `forget()`).

### `export_state`

```gdscript
func export_state() -> Dictionary
```

The entries as plain data, sorted by key.

### `import_state`

```gdscript
func import_state(saved: Variant) -> bool
```

Restores `export_state()`. False (and nothing changes) when malformed, or for an empty kind or subject or an unknown source, which `note()` would refuse too.
