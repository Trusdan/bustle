# BustleScoringConfig

Inherits: `Resource`

The scorer's curves and settings. Anything left unset is neutral (a factor of 1.0, or the identity curve for a need), so nothing here is tuning until a project sets it.

## Properties

### `need_curves`

```gdscript
var need_curves: Dictionary[StringName, Curve] = {}
```

Need name → its response curve over pressure (0 to 1). A need with no curve uses its pressure, clamped to 0..1.

### `distance_curve`

```gdscript
var distance_curve: Curve
```

The distance falloff, a curve over metres. Null is no falloff (1.0).

### `mood_curves`

```gdscript
var mood_curves: Dictionary[StringName, Curve] = {}
```

Tag → a curve over the `mood` input, multiplied in for options with that tag. Tags with no curve, or no mood input, give 1.0.

### `pick_window`

```gdscript
var pick_window: float = 0.1
```

How close to the best score a candidate must be to be picked: within this part of it.

### `expected_thought_gain`

```gdscript
var expected_thought_gain: Callable = Callable()
```

An optional preview of how an option would make the agent feel: `func(ad: BustleAdvertisement, context: BustleScoreContext) -> float`. Unset is 1.0.
