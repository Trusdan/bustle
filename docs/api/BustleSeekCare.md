# BustleSeekCare

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

The seek-care goal, opt-in: an agent who needs care goes to someone, or somewhere, that can give it. Bustle names where; the host moves the body, gives the care and owns the recovery. Bustle keeps no health state: every answer comes from the ports each time.
**Who seeks care:** an agent whose `BustleHealthPort.needs_care()` is at or above `threshold`, who isn't downed (`BustleHealthBehaviour.is_downed()`) and who has a destination. `fill_inputs()` sets its `INPUT` to that need, so the `goal_def()` goal scores higher the more urgent the care.
**Where:** `destination_for()`: the holder of the first of `care_roles` that is held, by someone else who isn't downed (`BustleRolesPort.holder_of()`); else `care_place`, a place the world port knows (`BustleWorldPort.has_place()`). Who counts as a healer is the host's call: name the roles, and give them to whom it chooses.
**Arriving:** an agent target is reached in the same area (`BustleWorldPort.area_of()`), a place within `REACH` metres of it (by `where`), or by `can_reach` when set. Once there, the patient waits, so a healer whose `BustleTendJob.nearby` includes it can tend it; the tend job itself is unchanged.
Register a [BustleSeekCareAction](BustleSeekCareAction.md) for `ACTION` on each agent's runner. Nothing is random.

True when `patient` should seek care now: its need is at or above `threshold`, it isn't downed, and it has a destination (`destination_for()`).

### `need`

How urgently `patient` needs care, 0 to 1, when that is at or above `threshold` and it isn't downed; 0 otherwise (and for an unusable reading).

Where `patient` would go for care: `{kind: &"agent", target}` for the holder of the first held care role (not the patient, not downed), else `{kind: &"place", target}` for `care_place` when the world port knows it, else empty.

Where `id` is now, from `where`, else the world port's position of its area; null when `where` doesn't say.

### `goal_def`

```gdscript
static func goal_def(minutes: int = 30, band: int = 40) -> BustleGoalDef
```

The seek-care goal: band `band` (`BustleBands.PERSONAL` by default), tags `seek_care` and `travel` (so the downed gate blocks it too), scored by `INPUT` in a straight line, running `ACTION` and then waiting `minutes` game minutes where it arrived, for care. A failed run (nowhere to go) waits the same before the goal can be chosen again.
