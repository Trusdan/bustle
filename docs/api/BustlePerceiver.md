# BustlePerceiver

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Node3D`

Gives its actor senses. Place it at the actor's eyes, facing the way it looks (its -Z). It registers with the [BustlePerceptionSystem](BustlePerceptionSystem.md) under `actor_id`; pair it with a [BustlePerceivable](BustlePerceivable.md) with the same id if the actor can also be sensed. Differences between actors come from the `profile` data, never from code.
