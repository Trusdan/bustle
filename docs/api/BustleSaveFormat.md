# BustleSaveFormat

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

Inherits: `RefCounted`

Which save versions this version of Bustle reads, and why it refuses one. Every class with `export_state()` has a save format named after the class, such as `&"BustleDirector"`. Its version is the payload's `"version"` (the society's is `"schema"`). `check()` says whether a payload's version can be read, before or after `import_state()` refuses it: an older version is migrated one step at a time to the current one, and a newer one is always refused, with a reason. A class that has never written a version reads a missing one as version 1. See `docs/saves.md`.

## Methods

### `check`

```gdscript
static func check(format: StringName, saved: Variant) -> BustleImportReport
```

Whether this version of Bustle reads `saved`'s version for `format` (a class name such as `&"BustleDirector"`). The report's `BustleImportReport.schema` is the version the payload claims, or -1. On a refusal its errors give the reason: the version is newer than this version reads, there's no migration from it, or it's missing or not a whole number. Only the version is checked; `import_state()` still checks the rest.
