# BustleLifeStages

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `BustleLifeStagePort`

The life-stages module: each agent's age in game days, the stage that age falls in, and the gates that stage puts on its goals and options. Opt-in: a host makes one with [BustleLifeStageRules](BustleLifeStageRules.md) and gives it to each brain as `BustleBrain.life_stages`. Nothing is random; a stage comes from the age alone, and nobody is born or dies unless the host says so.
The host sets ages with `set_age()` or adds a newborn (or any new agent) with `birth()`. `advance_to()` moves every living age on with the clock, closed-form, so one long catch-up step gives exactly the state of many short ones. `note_death()` records a death: the agent stops aging, every goal and option is closed to it, and what it held (career, job claim, roles) is released. An agent with no age set has no stage and no gates. With rules that aren't valid (`error()` says why), the module stays ageless: no ages, no stages, no gates.

## Signals

### `stage_changed`

```gdscript
signal stage_changed(id: StringName, old_stage: StringName, new_stage: StringName)
```

`id`'s stage changed from `old_stage` to `new_stage` (either may be empty: no stage). Fires once per real change, never when an age stays in the same stage. A step that crosses several stages fires once per stage crossed, in order.

### `born`

```gdscript
signal born(id: StringName, age_days: float)
```

`birth()` added `id` at `age_days`.

### `died`

```gdscript
signal died(id: StringName, cause: String)
```

`note_death()` recorded `id`'s death, with the host's `cause`.

### `vacated`

```gdscript
signal vacated(id: StringName, kind: StringName, what: StringName)
```

A death released something `id` held: `kind` is `career`, `job` or `role`, and `what` the career, posting or role. Refilling it is the host's call.

## Methods

### `error`


Why `rules` can't be used, or empty when they can. Checked once and kept; see `revalidate()`.

### `revalidate`

```gdscript
func revalidate() -> String
```

Checks `rules` again, after they were changed in place. Returns `error()`.

### `now`

```gdscript
func now() -> int
```

The game minute the ages were last moved on to (`advance_to()`).

### `set_age`

```gdscript
func set_age(id: StringName, days: float) -> bool
```

Sets `id`'s age to `days` game days, as of `now()`, and moves it to the stage that age falls in, emitting `stage_changed` when that is a different stage. False, changing nothing, for an empty id, an age that is negative or not finite, a dead agent, or rules that aren't valid.

### `birth`

```gdscript
func birth(id: StringName, days: float = 0.0) -> String
```

Adds `id` at `days` (0: a newborn), as of `now()`, emitting `born` and then `stage_changed` into its first stage. Returns why it was refused, or empty: an empty id, an agent that already has an age or has died, a bad age, an age below the first stage, or rules that aren't valid.

### `advance_to`

```gdscript
func advance_to(minute: int) -> bool
```

Moves every living age on to game minute `minute`, in whole minutes of `BustleLifeStageRules.minutes_per_day` a day. Every stage crossed fires `stage_changed` once, all agents' crossings in the order they happened (ties in id order). Ages come from the minute alone, so one call gives the same state and signals as many shorter ones. False, changing nothing, for a minute before `now()` or rules that aren't valid.

### `note_death`

```gdscript
func note_death(id: StringName, cause: String) -> String
```

Records `id`'s death from `cause` (a host string Bustle doesn't read), at `now()`. Emits `died`, then releases what it held, emitting `vacated` for each: its career (`careers`), its job claim (`jobs`) and its roles (`roles`, in name order). From then on it doesn't age, `set_age()` refuses it and every goal and option is closed to it. Returns why it was refused, or empty: an unknown or already dead agent, or an empty cause.

### `allows_goal`


False when `id` has died or its stage blocks any of `tags` (a goal's id and tags).

### `allows_affordance`

```gdscript
func allows_affordance(id: StringName, tags: StringName[]) -> bool
```

False when `id` has died or its stage blocks any of `tags` (an option's advertisement tags).

### `export_state`

```gdscript
func export_state() -> Dictionary
```

Every age, stage and death as plain data, in id order: `ages` (at `now()`), `stages`, `anchors` (each age as `[days, minute]`, so aging carries on exactly), `dead` (`{cause, at}`) and `now`.

### `import_state`

```gdscript
func import_state(saved: Dictionary) -> bool
```

Restores `export_state()`'s state (or a version 1 save, with ages as of minute 0), without emitting anything. False, changing nothing, for another version, an age that is negative or not finite, a stage or death for an agent with no age, a stage id the rules don't have, a bad death record, or rules that aren't valid. A stage is restored as saved, even if the rules have changed since and it no longer matches the age; the next `set_age()` or `advance_to()` moves it on.
