# BustleLifeStages

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `BustleLifeStagePort`

The life-stages module: each agent's age in game days, the stage that age falls in, and the gates that stage puts on its goals and options. Opt-in: a host makes one with [BustleLifeStageRules](BustleLifeStageRules.md) and gives it to each brain as `BustleBrain.life_stages`. Nothing is random; a stage comes from the age alone.
The host sets ages with `set_age()`. An agent with no age set has no stage and no gates. With rules that aren't valid (`error()` says why), the module stays ageless: no ages, no stages, no gates.

## Signals

### `stage_changed`

```gdscript
signal stage_changed(id: StringName, old_stage: StringName, new_stage: StringName)
```

`id`'s stage changed from `old_stage` to `new_stage` (either may be empty: no stage). Fires once per real change, never when an age stays in the same stage.

### `set_age`


### `import_state`

```gdscript
func import_state(saved: Dictionary) -> bool
```

Restores `export_state()`'s state, without emitting `stage_changed`. False, changing nothing, for another version, an age that is negative or not finite, a stage for an agent with no age, a stage id the rules don't have, or rules that aren't valid. A stage is restored as saved; the next `set_age()` moves it on if the rules have changed since.
