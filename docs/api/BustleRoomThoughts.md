# BustleRoomThoughts

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

The environment module: thoughts from the room an agent is in. The host computes rooms and their scores and reports them through the environment port ([BustleEnvironmentPort](BustleEnvironmentPort.md)); this module turns them into held thoughts with [BustleRoomThought](BustleRoomThought.md) rules.
`sync()` holds, for each score of the agent's room, the most extreme high rule it meets (the highest `BustleRoomThought.at_least`) and the most extreme low rule (the lowest `BustleRoomThought.at_most`), so a better score gives a better thought. Every other rule thought is dropped, so leaving the room, or its scores changing, clears or swaps them. A score the room doesn't have is unset and meets no rule. Thoughts go through the mood's `set_held`, so one of each is held at most. Rule thought ids must be the module's own: `sync()` drops any held thought with a rule's id. Nothing is random.
With no environment port, the default one (no rooms) or no mood, there are no environment thoughts and nothing errors.

### `chosen`

```gdscript
func chosen(room: StringName) -> BustleRoomThought[]
```

The rules `room` meets now: per score, the most extreme high rule and the most extreme low rule it meets, in `BustleEnvironmentPort.SCORES` order. Ties go to the rule added first. Empty for no room.

### `sync`

```gdscript
func sync(id: StringName, mood: Object = null) -> StringName[]
```

Brings `id`'s environment thoughts in line with its room now. On `mood` (anything with `set_held(def, held, details)`, such as a `BustleMood`) it drops every rule thought not chosen, then holds the chosen ones with `room`, `score` and `value` in their reason. Returns the chosen thought ids, sorted.

### `thoughts_of`

```gdscript
func thoughts_of(id: StringName) -> StringName[]
```

The thought ids chosen for `id` at its last sync, sorted.

### `forget`

```gdscript
func forget(id: StringName, mood: Object = null) -> void
```

Drops `id`'s environment thoughts from `mood` and forgets it (for an agent that leaves the society).

### `export_state`

```gdscript
func export_state() -> Dictionary
```

What each agent was last synced to, as plain data: `{agent: {room, thoughts}}`, sorted. The thoughts themselves are saved with the mood.

### `import_state`

```gdscript
func import_state(saved: Variant) -> bool
```

Restores `export_state()`, replacing what's kept. False (and nothing changes) for malformed data or a thought id no rule has. The next `sync()` brings the mood in line; holding a thought that is already held adds no second one.
