# BustleFearDef

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

One fear, as data: the event that forms it, what it makes the agent avoid and for how long. [BustleAspirations](BustleAspirations.md) reads it. Bustle ships none; events, goals and inputs are the host's names.
