# BustleRomance

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

The romance module: the courtship ladder of none, courting, partner, engaged and married. Every status is a relationship kind written both ways through the social port (`BustleSocialPort.set_kind()`), so the built-in store and a bridge to a social engine both carry it.
`update()` moves a pair along the ladder from causes and state alone. Courting starts when both opinions and their compatibility reach the [BustleRomanceRules](BustleRomanceRules.md) lines; it becomes a partnership after the courting days if both opinions reach the partner line. Engaged and married come only from `request()` with the host's `confirm_hook` approving. A courting or partnered pair breaks up when either opinion falls below its release line; an engaged or married pair only when the host calls `end()` (which ends any status). Both then get the breakup thought. After a breakup, the pair can court again only once its lower opinion has been below the courting release line and climbed back, so a breakup sticks until something changes. An agent with a partner or more never starts courting anyone else, and courting is one at a time.
An agent gets jealous when its partner (courting or above) takes to a third agent: the partner's opinion of them reaches `BustleRomanceRules.jealousy_opinion` (`update_all()`), or the partner does one of `BustleRomanceRules.jealousy_verbs` to them (`notice()`). The host records family with `link_family()`; family is never courted. A host `ratings_policy` can veto any step up the ladder. Nothing is random. With rules that aren't `BustleRomanceRules.is_valid()`, `update()` changes nothing.

### `update`

```gdscript
func update(a: StringName, b: StringName, now: int, mood_a: Object = null, mood_b: Object = null) -> StringName
```

Moves the pair along the ladder at game minute `now`: a courting or partnered pair breaks up below its release line; else courting or partner forms when the lines are met (courting only for a pair that is armed: never broken up, or below the courting release line since). Engaged and married never lapse here. `mood_a` and `mood_b` (anything with `add_thought`) get the breakup thought. Returns the status after.

### `update_all`

```gdscript
func update_all(ids: StringName[], now: int, mood_of: Callable = Callable()) -> void
```

Every pair of `ids`, in id order (see `update()`), then jealousy over opinion: each agent whose partner's opinion of another of `ids` has reached `BustleRomanceRules.jealousy_opinion` gets jealous, once, until that opinion has fallen below `BustleRomanceRules.jealousy_release`. `mood_of` is `func(id) -> Object` for the thoughts, or unset; it is asked only when one is due.

### `may_court`

```gdscript
func may_court(a: StringName, b: StringName) -> bool
```

True when `a` and `b` may start courting: neither holds a `BustleRomanceRules.blocked_kinds` kind toward the other, and neither is already courting, partnered, engaged or married to anyone (one courtship at a time, so a partnership never leaves a second courtship behind). Affairs have no path, whatever `BustleRomanceRules.affairs_enabled` says. The `ratings_policy` is asked separately, just before a step.

### `request`

```gdscript
func request(a: StringName, b: StringName, status: StringName, now: int) -> bool
```

Asks to move the pair up to `status` (`ENGAGED` from partner, or `MARRIED` from engaged) at game minute `now`. Only `confirm_hook` can approve it, and only if `ratings_policy` allows it (asked first). False (and no change) for any other step, or when the hook refuses or is unset.

### `end`

```gdscript
func end(a: StringName, b: StringName, now: int, mood_a: Object = null, mood_b: Object = null) -> bool
```

Ends the pair's relationship at game minute `now` (one of them chose to, as the host decides), whatever its status; this is the only way an engaged or married pair ends. Both get the breakup thought. The pair can't court again until its lower opinion has been below the courting release line. False when they have none.

### `export_state`

```gdscript
func export_state() -> Dictionary
```

Every pair's status, since, history and whether it is armed to court again (false after a breakup until its lower opinion has been below the courting release line), as plain data, keyed by pair; and the jealousy felt over opinions under `jealousy`. Sorted. The kinds themselves, family included, are saved by the social port.

### `import_state`

```gdscript
func import_state(saved: Variant) -> bool
```

Restores `export_state()`, replacing every pair. False (and nothing changes) when it is malformed or holds a status off the ladder. A pair saved without `armed` is armed, and a save without `jealousy` has felt none.

### `link_family`

```gdscript
func link_family(a: StringName, b: StringName, relation: StringName) -> bool
```

Records that `b` is `a`'s `relation` (a key of `FAMILY`), writing the kind both ways through the social port (the other way, its counterpart). Family is never courted (`BustleRomanceRules.blocked_kinds`). Bustle records family only when the host says so. False for an unknown relation, a missing or same agent, or a port that keeps no kinds.

### `unlink_family`

```gdscript
func unlink_family(a: StringName, b: StringName, relation: StringName) -> bool
```

Takes away what `link_family()` recorded. False when it couldn't have been recorded.

### `notice`

```gdscript
func notice(actor: StringName, verb: StringName, target: StringName, mood_of: Callable = Callable()) -> bool
```

Tells romance that `actor` did the interaction `verb` to `target`. When it is one of `BustleRomanceRules.jealousy_verbs`, and `actor` is courting or bonded to someone other than `target`, that partner gets jealous, once for this interaction, with `target` as the rival. `mood_of` gives the partner's mood for the thought. True when someone got jealous.
