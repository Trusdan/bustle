# BustleRomance

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

The romance module: the courtship ladder of none, courting, partner, engaged and married. Every status is a relationship kind written both ways through the social port (`BustleSocialPort.set_kind()`), so the built-in store and a bridge to a social engine both carry it.
`update()` moves a pair along the ladder from causes and state alone. Courting starts when both opinions and their compatibility reach the [BustleRomanceRules](BustleRomanceRules.md) lines; it becomes a partnership after the courting days if both opinions reach the partner line. Engaged and married come only from `request()` with the host's `confirm_hook` approving. A pair breaks up when either opinion falls below its release line, or when the host calls `end()`; both then get the breakup thought. An agent with a partner or more never starts courting anyone else, and courting is one at a time. Nothing is random.

### `update`


Moves the pair along the ladder at game minute `now`: a breakup below the release line; else courting or partner when the lines are met. `mood_a` and `mood_b` (anything with `add_thought`) get the breakup thought. Returns the status after.

### `may_court`

```gdscript
func may_court(a: StringName, b: StringName) -> bool
```

True when `a` and `b` may start courting: neither holds a `BustleRomanceRules.blocked_kinds` kind toward the other, and neither is already courting, partnered, engaged or married to anyone (one courtship at a time, so a partnership never leaves a second courtship behind). Affairs have no path, whatever `BustleRomanceRules.affairs_enabled` says.

### `request`

```gdscript
func request(a: StringName, b: StringName, status: StringName, now: int) -> bool
```

Asks to move the pair up to `status` (`ENGAGED` from partner, or `MARRIED` from engaged) at game minute `now`. Only `confirm_hook` can approve it. False (and no change) for any other step, or when the hook refuses or is unset.

### `end`

```gdscript
func end(a: StringName, b: StringName, now: int, mood_a: Object = null, mood_b: Object = null) -> bool
```

Ends the pair's relationship at game minute `now` (one of them chose to, as the host decides). Both get the breakup thought. False when they have none.

### `export_state`


Every pair's status, since and history, as plain data, sorted. The kinds themselves are saved by the social port.

### `import_state`

```gdscript

```

Restores `export_state()`, replacing every pair. False (and nothing changes) when it is malformed or holds a status off the ladder.
