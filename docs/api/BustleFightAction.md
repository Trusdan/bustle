# BustleFightAction

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `BustleActionHandler`

`fight`: engages the agent's threat through the combat port with its intent, and names it as the output's `attack_target`. Every tick it works the intent out again (`BustleConflict.update_intent()`) and engages again when it changed, so a fight can escalate. Done when the port reports the fight RESOLVED (then `BustleConflict.finish()` reports it) or the conflict was cleared. Fails with `no_threat` when the agent has none.
