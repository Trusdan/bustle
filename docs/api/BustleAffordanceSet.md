# BustleAffordanceSet

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

The placed affordances of a population, by id, so one generic "use something" goal can score them all. `advertisements()` gives the scorer one advertisement per affordance an agent may use (refused, full and unaffordable ones are left out), in id order.

### `advertisements`

func advertisements(agent: StringName, now: int, distance: Callable = Callable(), trade: BustleTradePort = null, leisure: BustleLeisure = null, only: StringName[] = []) -> BustleAdvertisement[]

What `agent` is offered at minute `now`: one advertisement per affordance it may use, in id order. `distance` maps an affordance to its distance (empty: 0). Only `only` (when not empty) are considered: a host passes the ones the agent knows of.
