# BustleMentalStateDef

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

One mental state, as data: what it does (`behaviour`), whether it's a low or a high state, how personality weighs it, what circumstance it needs and how long it lasts. What a state can do is fixed by `Behaviour`; there is no field for harming anyone, the agent included, or for any intent.
