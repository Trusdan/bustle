# BustleCrime

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Desperate theft, in the `BustleBands.GUARDED` band. Nothing here is left to chance: an agent steals when its circumstances and its personality add up, every time they do, and never otherwise. There is no limit on how much crime a place sees; how often it happens follows from who lives there and how hard pressed they are.
`consider()` runs the guards, in order. Each must pass: 
1. crime is allowed: the developer setting `BustleCrimeConfig.SETTING` and `enabled` (neither is a game option); 
2. the agent is a known agent, not in `exempt` and not held by `is_locked`; 
3. need: one of `BustleCrimeConfig.needs` presses at least `BustleCrimeConfig.min_need`, and the agent owns nothing that eases it (an agent that already has what it needs, stolen or not, isn't driven to take more); 
4. personality: that pressure plus `Σ weight × (slider − 50) / 100` over `BustleCrimeConfig.slider_weights` reaches `BustleCrimeConfig.threshold` (honesty holds an agent back; greed and boldness push it on); 
5. opportunity: an item in the agent's area, owned by someone else, not protected, that eases the need, where nobody else would see (`is_observed`). 
When they all pass, the agent's `fact.steal` input is 1 (`fill_inputs()`), so the `steal` goal from `goal_defs()` can run its `steal` action, which moves the item through the property port and emits `theft`. A theft only moves an existing item, and never makes anyone mean to kill: what follows is for the host.

## Methods

### `consider`

```gdscript
func consider(agent: StringName, now: int) -> Dictionary
```

Runs the guards for `agent` at minute `now` (see the class description). Returns what it would steal, `{item, owner_id, place, need, pressure, score}`, and remembers it as the agent's target; empty (and no target) when any guard fails.

### `target_of`

```gdscript

```

`agent`'s current target (a copy), or empty.

### `fill_inputs`

```gdscript
func fill_inputs(agent: StringName, inputs: Dictionary[StringName, float]) -> void
```

Writes `INPUT` into `inputs`: 1 while `agent` has a target, else erased.

### `steal`

```gdscript
func steal(agent: StringName, now: int) -> Dictionary
```

`agent` takes its target at minute `now`, if every guard still passes for that same item: the property port moves it to the agent and `theft` is emitted. The target is cleared either way. Returns `{ok: true, item}` or `{ok: false, reason}`.

### `clear`

```gdscript
func clear(agent: StringName) -> void
```

Forgets `agent`'s target.

### `goal_defs`

The one GUARDED goal: `steal`, eligible only while `INPUT` is 1, running the `steal` action.
