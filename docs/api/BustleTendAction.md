# BustleTendAction

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `BustleActionHandler`

`tend`: asks the host to have the agent care for its patient (`BustleTendJob.patient_for()`), through `BustleTendJob.tend()`. It names the patient in the output (`tend`) so the host can move and animate the healer. Done when the host did the care; failed with `no_patient` or `care_refused` otherwise.
