Inherits: `BustleActionHandler`

`fetch_healer`: goes on with the agent's errand (`BustleFetchHealer.errand_of()`). It moves and arrives by the fetch-help rule (`BustleFetchHelpAction.approach()`): while more than `BustleFetchHelpAction.REACH` metres from the healer it asks the host to move the agent there (`move_to` and `talk_to` in the output); once there, or at once without positions, it tells the healer (`BustleFetchHealer.arrive()`). The patient is named in the output (`fetch_healer`). Done once it arrived, or when the errand ended.
