# BustleEnvironmentPort

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Rooms and surroundings. The host computes its rooms and their scores; Bustle never detects rooms or looks at what is in them. A host either extends this (overriding `room_of()` and `scores()`) or fills the built-in store with `set_room()` and `set_scores()`. The standalone default has no rooms and no scores. An agent in a room is indoors and one in no room outdoors (`conditions()`), for needs that rise or fall with that.

## Constants

### `SCORES`

```gdscript
const SCORES = Array[StringName]([&"beauty", &"comfort", &"cleanliness", &"impressiveness"])
```

The room scores, each from 0 to 1. A score a room doesn't have is unset, not 0.

### `INDOORS`

```gdscript
const INDOORS = &"indoors"
```

The need condition for an agent in a room.

### `OUTDOORS`

```gdscript
const OUTDOORS = &"outdoors"
```

The need condition for an agent in no room.

## Methods

### `room_of`

```gdscript
func room_of(id: StringName) -> StringName
```

The room `id` is in, or empty.

### `scores`

```gdscript
func scores(room: StringName) -> Dictionary[StringName, float]
```

`room`'s scores (a subset of `SCORES`, each from 0 to 1). Empty for no room or an unscored one.

### `is_indoors`

```gdscript
func is_indoors(id: StringName) -> bool
```

True while `id` is indoors: by default, while it is in a room. A host can override it (a roofless yard counted as a room, say).

### `conditions`

```gdscript
func conditions(id: StringName) -> StringName[]
```

The need conditions for `id` now: `INDOORS` while it `is_indoors()`, else `OUTDOORS`. Add them to the conditions passed to `BustleNeedSet.advance()`.

### `conditions_of`

```gdscript
static func conditions_of(port: BustleEnvironmentPort, id: StringName) -> StringName[]
```

`conditions()` for `id` from `port`, or none when there is no port: with no environment port, the environment changes no need.

### `set_room`

```gdscript
func set_room(id: StringName, room: StringName) -> bool
```

Puts `id` in `room` (empty: in no room). False for an empty id.

### `set_scores`

```gdscript
func set_scores(room: StringName, values: Dictionary) -> bool
```

Replaces `room`'s scores with `values` (score → value; empty clears them). False (and no change) for an empty room, a score not in `SCORES` or a value outside 0 to 1.

### `export_state`

```gdscript
func export_state() -> Dictionary
```

The built-in store as plain data: `{"rooms": {agent: room}, "scores": {room: {score:
value}}}`, sorted. A host that overrides the lookups saves its own rooms.

### `import_state`

```gdscript
func import_state(saved: Variant) -> bool
```

Restores `export_state()`, replacing the store. False (and nothing changes) for malformed data, an unknown score or a value outside 0 to 1.
