# BustleSeekCareAction

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `BustleActionHandler`

`seek_care`: takes the agent to where it can get care (`BustleSeekCare.destination_for()`). While it still has to get there, it asks the host to move it (`move_to` when a position is known, `talk_to` for a person, and `seek_care`, the target, in the output); Bustle names where, the host moves the body. Done once there, or when the agent no longer needs to seek care (it recovered, or is downed). Failed with `no_care` when there is nowhere to go.
