# BustleNeedDef

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

One need, as data: how fast its pressure rises (0 = fine, 1 = urgent), under which conditions, how it changes while other conditions hold, and its response curve. Bustle ships no needs of its own; a host defines them. Every rate defaults to 0.
Each game hour the pressure changes by `rate_per_hour` × the agent's `need.<id>.rate` modifier (only while one of `rises_when` holds, or always when that is empty), plus `condition_rates` for every condition that holds. The rate modifier scales the rise only, never a fall.
