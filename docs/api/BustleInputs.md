The fixed vocabulary of scorer inputs. An input key is a family and a name, such as `need.food` or `trait.sociability`; the families are fixed here, and the names within them are data. Adding a family is a reviewed code change; using one is data. Input values reach the scorer already normalised by whoever supplies them.

### `is_valid_input`


True when `key` is a well-formed input: `health`, `mood`, or a family followed by one or more dot-separated names of lower-case letters, digits and underscores.
