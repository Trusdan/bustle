# BustleMentalConfig

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

The numbers behind [BustleMentalState](BustleMentalState.md). A starting point, not tuning: a host sets its own. The modifiers `mental.break_threshold` (added to `break_threshold`, so traits can move it) and `mental.inspired` (above 0: a trait that opts in to inspiration) adjust them per agent.

## Constants

### `SETTING`

```gdscript
const SETTING = "bustle/simulation/mental_states"
```

The project setting a developer or a test turns mental states off with (default on). It isn't a game option.
