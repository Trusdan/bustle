# BustleModifierSet

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Numbers that sources (a trait, a mood, an injury) add to or multiply, by key, so modules read one value without knowing where its parts came from. A key is dot-separated lower-case names, such as `need.company.rate` or `tag.social.mult`.

`value(key, base) = (base + Σ add) × Π mult`, with every source applied in sorted source-id order, so the result never depends on the order sources were set. A source has at most one entry per key; setting it again replaces it.
