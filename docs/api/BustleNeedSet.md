# BustleNeedSet

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

One agent's needs: each [BustleNeedDef](BustleNeedDef.md) and its current pressure, from 0 (fine) to 1 (urgent). `advance()` moves every pressure on by game minutes under the conditions that hold (the host names them: `awake`, `asleep`, `alone` and so on). Changes are linear and clamped, so one long step equals many short ones under the same conditions, which is what OFF_SCREEN agents need. Using an option lowers (`relieve()`) or raises (`raise()`) a pressure. `fill_inputs()` gives the scorer its `need.<id>` inputs.
**The social pair.** Two needs cover loners and extroverts with the same rules: one that rises while `alone` (company) and one that rises while `crowded` (too many people). `social_conditions()` names which holds from how many people are near and the agent's crowd tolerance (the `social.crowd_tolerance` modifier, base `DEFAULT_CROWD_TOLERANCE`).

### `advance`

```gdscript
func advance(minutes: float, conditions: StringName[], modifiers: BustleModifierSet = null) -> void
```

Moves every need on by `minutes` of game time under `conditions`. Each need's rise is scaled by the `need.<id>.rate` modifier in `modifiers` (base 1). Negative or non-finite minutes do nothing.

### `relieve`


### `raise`


Raises need `id` by `amount` (a side effect). Ignored as for `relieve()`.
