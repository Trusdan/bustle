# BustleHealthEffect

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

How one host capacity scales one modifier key: at full capacity the key is untouched, and below it the key is multiplied by `at_zero + (1 - at_zero) × capacity^power`. Several effects on one key multiply together. Experimental defaults are in `BustleHealthConfig.defaults()`.

The multiplier at capacity 0. Not negative.

### `power`

```gdscript

```

The curve's shape: 1 is a straight line, above 1 bends it down (slower at middling capacity). Above 0.
