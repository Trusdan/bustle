# BustleSkillDef

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

One skill, as data: its id, its top level, how much practice each level costs and how it fades without practice. [BustleSkills](BustleSkills.md) reads it. Bustle ships no skills; the host supplies every def. The numbers here are experimental defaults.

## Properties

### `id`

```gdscript
var id: StringName = &""
```

Its id, chosen by the host (for example `cooking`).

### `max_level`

```gdscript
var max_level: int = 20
```

The highest level. A point of skill is one band of `xp_curve`.

### `decay_floor`

```gdscript
var decay_floor: float = 0.0
```

The level decay stops at. Skill at or below it never fades.

### `decay_per_day`

```gdscript
var decay_per_day: float = 0.0
```

Levels lost per game day while above `decay_floor`. 0: no decay.

### `xp_curve`

```gdscript
var xp_curve: float[] = [...]
```

XP needed for each level, from level 0 to 1 onwards. The last entry repeats for the levels after it, so `[100.0]` costs 100 XP a level.

## Methods

### `is_valid`

```gdscript
func is_valid() -> bool
```

True when it can be used: an id, a positive top level, a floor in `0..max_level`, a non-negative decay rate, and a curve of positive finite costs.

### `cost_of`

```gdscript
func cost_of(band: int) -> float
```

The XP that level `band` costs (from `band` to `band` + 1).

### `level_for`

```gdscript
func level_for(xp: float) -> float
```

The level `xp` gives: whole levels for each band paid, plus the fraction of the next, never above `max_level`.

### `xp_for`

```gdscript
func xp_for(level: float) -> float
```

The XP that reaches `level` exactly, the inverse of `level_for()`.

### `max_xp`

```gdscript
func max_xp() -> float
```

The XP at `max_level`; practice past it is not kept.
