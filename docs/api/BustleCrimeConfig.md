The numbers behind [BustleCrime](BustleCrime.md). Nothing here is a chance: a theft happens when its circumstances and the agent's personality add up, every time they do.

## Constants

### `SETTING`

```gdscript
const SETTING = "bustle/simulation/npc_crime"
```

The project setting a developer can turn agents' crime off with (default on). It isn't a game option: a host doesn't show it to players.

## Properties

### `needs`

```gdscript
var needs: StringName[] = [...]
```

The needs that can drive an agent to steal (it steals only something that eases one).

### `min_need`

```gdscript
var min_need: float = 0.6
```

How pressing a need must be (0 to 1) before the agent even considers stealing.

### `threshold`

```gdscript
var threshold: float = 1.0
```

What the need's pressure plus the personality terms must reach for the agent to steal.

### `slider_weights`

```gdscript
var slider_weights: Dictionary[StringName, float] = {...}
```

Personality slider → weight: each adds `weight × (slider − 50) / 100`. By default honesty holds an agent back twice as hard as greed and boldness push it on.

## Methods

### `crime_allowed`

```gdscript
static func crime_allowed() -> bool
```

True when the developer setting lets agents commit crimes (on unless set to false).
