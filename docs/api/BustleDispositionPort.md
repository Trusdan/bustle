How one actor regards another: hostile, neutral or friendly. A host plugs in its own source (factions, reputation) by extending this class and overriding `disposition()`. The standalone default reads a [BustleDispositionTable](BustleDispositionTable.md) if one is given, and is neutral otherwise.
