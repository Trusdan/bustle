# BustleSchedule

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

One agent's routine in play: which block of its [BustleScheduleDef](BustleScheduleDef.md) is current, the scorer's `schedule.*` inputs, and attendance. A block is on time when the agent turns up within its lateness tolerance, late when it turns up after that, and missed when it never turns up before the block ends. Time is whole game minutes from the clock port; the season is the clock port's `BustleClockPort.season()` (a block carried over from the night before is read in the current season, and `report()` reads a past day in the season it is given, so pass that day's season across a change of season).
**Wages.** A block with a `BustleScheduleBlock.wage` pays it once, after it ends, if it was attended (on time or late): `settle()` pays every such block through a [BustleTradePort](BustleTradePort.md). Its payer is the block's own, else the `employer` when it was attended, fixed then and saved. A missed block pays nothing; a payment the payer can't make stays owed (kept past the attendance window) and is tried again on every settle until paid.

### `fill_inputs`


Writes the scorer's inputs for minute `now`: `schedule.<activity>` is 1 for the current block, and `FREE_TIME` is 1 when there is none. The routine's other activity inputs (and free time, while a block is current) are erased; other inputs are left alone.

The agent is doing `activity` at minute `now`. When that is the current block's activity, records its arrival (the first one counts) and returns `ON_TIME` or `LATE`; otherwise returns empty.

### `settle`

```gdscript
func settle(now: int, agent: StringName, trade: BustleTradePort, employer: StringName = &"") -> Dictionary[]
```

Pays `agent`'s wages for every attended block that has ended by minute `now` and isn't paid yet, through `trade`. Each payer was fixed when the block was attended; `employer` only pays records saved without one. Returns one `{start, activity, amount, payer, paid}` per wage tried, in start order; an unpaid one stays owed.
