# BustleSenseTarget

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

What the project reports about one target to one observer each tick. The project casts the sight ray and fills in `line_of_sight`; the core never touches physics.

## Properties

### `position`

```gdscript
var position: Vector3 = Vector3(0, 0, 0)
```

Where the target is.

### `visibility`

```gdscript
var visibility: float = 1.0
```

How visible it is (from [BustleVisibilityModel](BustleVisibilityModel.md)); 1.0 is a standing, walking target in full light.

### `noise_radius`

```gdscript
var noise_radius: float = 0.0
```

How far its noise carries, in metres (from [BustleNoiseModel](BustleNoiseModel.md)).

### `line_of_sight`

```gdscript
var line_of_sight: bool = true
```

True when nothing blocks this observer's view of the target.

### `carries_light`

```gdscript
var carries_light: bool = false
```

True while the target carries a lit light of its own (a torch, a lantern). Profiles whose `BustlePerceptionProfile.sight_light` is `BustlePerceptionProfile.SightLight.CARRIED_LIGHT_ONLY` see only such targets.
