# BustleFindPerson

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Works out where to look for someone, in order: sense them now (`sense`); remember where they were ([BustleMemory](BustleMemory.md)); guess from their routine (`routine`); ask the people the seeker can ask (`ask_whom`), whose memories answer; or give up. Giving up starts a cooldown for that seeker and target, during which `find()` fails at once, so an agent doesn't search for someone nobody knows about every tick. What is learnt by asking or guessing is noted in the seeker's memory (`BustleMemory.TOLD`, `BustleMemory.ROUTINE`).
The host supplies each source as a `Callable`; empty ones are skipped. Cooldowns live only in memory: an ended one is dropped when that search runs again, and none are saved.

## Methods

### `find`

```gdscript
func find(seeker: StringName, target: StringName, now: int) -> Dictionary
```

Where `seeker` should look for `target` at minute `now`: `{found, how, area, position, from}`. `how` is one of the constants above; `from` is who answered when asked. When nothing works, `found` is false, `how` is `UNKNOWN` and a cooldown starts.

### `cooldown_until`

```gdscript
func cooldown_until(seeker: StringName, target: StringName) -> int
```

When `seeker` may search for `target` again (a game minute), or -1 for now.
