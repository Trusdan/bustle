# BustleRolesPort

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Who holds which role (a job or an office). A host extends this and overrides `holder_of()` and `roles_of()`, and emits `holder_changed` when a holder changes. The standalone default is a static table, read from a [BustleRoleTable](BustleRoleTable.md) if one is given, changed with `set_holder()`. What a role means is the host's business.

## Signals

### `holder_changed`

```gdscript
signal holder_changed(role: StringName, old: StringName, new: StringName)
```

`role` passed from `old` to `new` (either may be empty).

## Methods

### `holder_of`

```gdscript
func holder_of(role: StringName) -> StringName
```

Who holds `role`, or empty.

### `roles_of`

```gdscript
func roles_of(id: StringName) -> PackedStringArray
```

The roles `id` holds, sorted. Empty for an unknown or empty id.

### `set_holder`

```gdscript
func set_holder(role: StringName, id: StringName) -> void
```

Gives `role` to `id` (empty vacates it), emitting `holder_changed` when that changes anything. Empty roles are ignored.
