# BustleCareers

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

The careers module: ranks on standing jobs. A career is not a second job: it is the agent's standing job (a role with a routine, see [BustleScheduleRoster](BustleScheduleRoster.md)) held at a rank of a [BustleCareerDef](BustleCareerDef.md). The rank sets what the track's career block pays, through the agent's schedule (`BustleSchedule.wages`), so it is paid at the block's end like any shift and only if attended. While an agent attends an off-site career block it is away (`is_away()`), and the host takes it out of the world until the block ends.
`update()` closes whole days into a performance score (`day_performance()`: mood, skill and attendance) and reviews the agent after each window of `BustleCareerRank.review_days` days. A window at or above the rank's `BustleCareerRank.promote_if` makes a promotion due; at or below `BustleCareerRank.demote_if`, a demotion. `review_hook` grants or refuses it; with none, it is granted. Reviews can leave the agent a thought, when it has a mood.
Agents with no career keep their job, routine and wages exactly as before. An agent whose job is no longer the track's role leaves the track. Nothing is random: the same mood, skill and attendance give the same reviews.

### `day_performance`

```gdscript

```

One day's performance, from 0 to 1: the weighted mean of the terms given, each from 0 to 1. `mood` always counts; `skill` and `attendance` only when not NAN (a track with no skill; a day with no career block). `(mood_weight × mood + skill_weight × skill + attendance_weight × attendance) ÷ (sum of the
weights used)`.

### `update`

```gdscript
func update(id: StringName, now: int, mood: Object = null) -> Dictionary[]
```

Brings `id`'s career up to game minute `now`. Each whole game day whose career blocks have all ended is closed into a `day_performance()` from `mood` (anything with a `mood` number, such as a `BustleMood`; null: `neutral_mood`), the skill level now and that day's attendance at the career block. Each time a window has `BustleCareerRank.review_days` days, the agent is reviewed at the end of the last day, and the next window starts. Call it at least every few game days (the schedule keeps 7 days of attendance). Given the same mood, skill and attendance, one long call gives the same reviews as many short ones. Returns one `{at, performance, outcome, rank}` per review.

### `fill_inputs`

```gdscript

```

Sets `PROMOTION_GRANTED` to true in `inputs` (an ambition's facts) from a granted promotion of `id` until its next review, so an ambition to be promoted completes.

### `import_state`

```gdscript
func import_state(saved: Variant) -> bool
```

Restores `export_state()`, replacing every career. False (and nothing changes) when the data is malformed or names a track or rank there's no def for. A save without the review clock (`closed`, `window`, `promoted`) starts it afresh from `since`. It doesn't check who holds which role: restore the roles first.
