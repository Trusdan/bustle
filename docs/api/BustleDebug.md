# BustleDebug

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Whether Bustle's debug tools may run. They run only in debug builds (the editor and debug exports); in a release export the console and overlay do nothing. Hosts can also leave `addons/bustle/debug/` out of release exports with an export filter.

## Properties

### `debug_build_override`


For tests only: when not null, overrides whether this counts as a debug build.
