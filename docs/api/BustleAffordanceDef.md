A kind of smart object, as data: what using it does to needs, its tags, how many can use it at once, how long a reservation holds and its price. A bed, a bench and a stall are each one def, placed many times as [BustleAffordance](BustleAffordance.md)s.

### `item`


When set, each use buys this item from the owner (or payee) through `BustleTradePort.buy()`, at the port's price and from the host's stock, instead of paying `price`. Empty: an ordinary priced use.

### `others_mult`

```gdscript
var others_mult: float = 0.0
```

For agents other than the owner: their scores are multiplied by this. 0 refuses them, 1 treats them like the owner. Only applies to an owned affordance.
