# BustleVisibilityModel

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

How visible a target is: the light curve × posture × movement × a clothing factor, times the stealth-skill multiplier, clamped to `min_visibility..max_visibility`. 1.0 is a standing, walking target in full light with neutral clothing and no skill. It keeps no state; the numbers come from [BustleStealthRules](BustleStealthRules.md).

### `compute`

```gdscript
func compute(light_level: float, posture: int, movement: int, wear_factor: float = 1.0, skill: float = 0.0) -> float
```

The target's visibility. `light_level` is 0..1 (from a [BustleLightProbe](BustleLightProbe.md)); `wear_factor` is the project's clothing value (1.0 is neutral); `skill` is the target's stealth skill.
