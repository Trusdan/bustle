# BustleFleeAction

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `BustleActionHandler`

`flee`: runs straight away from the agent's threat (`move_to` in the output, aimed `BustleConflictConfig.flee_margin` past the safe distance so a body that stops a little short still gets there) until it is `BustleConflictConfig.flee_distance` away, then clears the conflict. Without positions it gets away at once. Done when the conflict is over.
