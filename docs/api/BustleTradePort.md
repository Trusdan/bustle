# BustleTradePort

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Money and buying, in the host's smallest unit (whole numbers). A host extends this to use its own wallets and shops. The standalone default keeps in-memory balances and a price list. It never creates or loses money: a payment moves an exact positive amount between two different, named agents who can afford it, and anything else fails without changing a balance.


Moves `amount` from `from` to `to`. False, changing nothing, when the amount isn't positive, an id is empty, they are the same, or `from` can't afford it.

### `buy`

```gdscript
func buy(id: StringName, item: StringName, seller: StringName) -> bool
```

`id` buys `item` from `seller` at its listed price. False, changing nothing, when it has no price, the price is negative, or the payment fails. A price of 0 succeeds without moving money.
