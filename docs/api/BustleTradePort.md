# BustleTradePort

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Money and buying, in one abstract unit (whole numbers): what the unit is, and any currencies behind it, is the host's business. A host extends this to use its own wallets and shops. The standalone default keeps in-memory balances and a price list. It never creates or loses money: a payment moves an exact positive amount between two different, named agents who can afford it, and anything else fails without changing a balance.
Stock belongs to the host: the default sells any listed item without limit. A host that keeps stock (or lends credit) overrides `can_buy()` and `buy()` together, so an item is only offered when `buy()` would go through, and `can_take()` and `take()` together for an owner using its own stock.

True when `buy()` would go through: `item` is sold, the ids are two different named agents, and `id` can pay `price_of()`. It changes nothing.

### `buy`

```gdscript

```

`id` buys `item` from `seller` at `price_of()`. False, changing nothing, when `can_buy()` says no. A price of 0 succeeds without moving money.

### `can_take`

```gdscript

```

True when `take()` would go through: `id` may take one `item` from its own stock. It changes nothing. Default: any named agent may, for any item.

### `take`

```gdscript
func take(id: StringName, item: StringName) -> bool
```

`id` takes one `item` from its own stock, without paying: no money moves. False, changing nothing, when `can_take()` says no. A host that keeps stock takes one off here.
