# BustleRoomThought

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

One environment thought rule, as data: while an agent is in a room whose `score` is at least `at_least` (a high rule) or at most `at_most` (a low rule), it holds `thought`. [BustleRoomThoughts](BustleRoomThoughts.md) reads it. Bustle ships none; the thresholds are the host's.
