# BustleSimRings

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Sorts a society's agents into simulation rings by where they are relative to the player, using the society's world and clock ports. It only classifies: a ring change touches nothing in the agent's state.

- **FULL:** in the player's area and within `BustleSimRingConfig.full_radius` of the player. - **LIGHT:** in the player's area but farther (or with no known position), or in an area next to the player's. - **OFF_SCREEN:** anywhere else. - **Hysteresis:** a FULL agent stays FULL until it is beyond the radius plus `BustleSimRingConfig.hysteresis`. - **Dwell:** after a change, an agent keeps its ring for `BustleSimRingConfig.min_dwell_seconds` whatever happens. A new agent gets its ring at once.
