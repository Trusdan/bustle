# BustleAmbitionTargets

Inherits: `RefCounted`

Who the courting and feud ambitions are about, from the society and its social port: fills the inputs [BustleAmbitions](BustleAmbitions.md) reads for `court_someone` and `settle_feud`.
**Courting** (`court_target`): another agent of the society in the same settlement (`settlement_of`), not family (`BustleAmbitionConfig.family_kinds`) and not gone for good (`is_gone`), whose opinion is at least `BustleAmbitionConfig.like_line`; the one it likes most, ties by id. The current target is kept while it still qualifies. `court_target_gone` is set only when the current target is gone for good and nobody else qualifies; when someone else does, the ambition simply turns to them. 
**Feuds** (`rival`): someone it counts as a rival (the social port's `rival` kind), not gone for good; the current one is kept, else the lowest opinion, ties by id. `rival_cleared` once the current rival no longer has the rival kind, and `rival_gone` once they're gone for good.
