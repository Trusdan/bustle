# BustlePerceivable

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Node3D`

Lets its actor be sensed. Place it where others look and listen (about chest height). Its owner keeps `visibility`, `noise_radius` and `carries_light` current (for example from [BustleVisibilityModel](BustleVisibilityModel.md) and [BustleNoiseModel](BustleNoiseModel.md)); the defaults are a visible, silent actor with no light.
