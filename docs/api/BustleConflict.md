# BustleConflict

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Fight, flee or fetch help, in the CRITICAL band. An agent that `notice()`s someone it regards as hostile (by the disposition port, never by opinion) takes a stance from its personality: bold or hot-tempered agents fight, timid ones fetch a nearby ally or flee. `fill_inputs()` writes the stance as the scorer's `threat.fight`, `threat.flee` and `threat.fetch_help` inputs, which the goals from `goal_defs()` read; the `fight`, `flee` and `fetch_help` actions carry them out. When a conflict ends, its inputs go and the agent's usual goals (its schedule) win again.
A fight is a scuffle unless a seeded roll against `BustleConflictConfig.lethal_chance` makes it lethal; a scuffle never kills (`filter_damage()`). Every fight that ends emits `assaulted`, and one that killed also `killed`, so a host can apply consequences. A `quarrel()` can turn into a scuffle without making anyone hostile.

## Methods

### `notice`

```gdscript
func notice(agent: StringName, other: StringName, now: int, nearby: StringName[] = []) -> StringName
```

`agent` notices `other` at minute `now`. Only when it regards `other` as hostile does it take a stance, which it returns (`FIGHT`, `FLEE` or `FETCH_HELP`; a fetcher picks the nearest ally in `nearby`). Empty otherwise, or when it's already in a conflict.

### `quarrel`

```gdscript
func quarrel(a: StringName, b: StringName, now: int, nearby: StringName[] = []) -> bool
```

`a` quarrels with `b` at minute `now`. With a chance of `BustleConflictConfig.quarrel_chance` scaled by `a`'s temper, it becomes a scuffle: `a` fights, and `b` takes its own stance. Nobody becomes hostile. True when it did.

### `stance_for`

```gdscript
func stance_for(agent: StringName, has_help: bool) -> StringName
```

The stance `agent` takes against a threat: `FIGHT` when the average of its boldness and temper reaches `BustleConflictConfig.fight_threshold`, else `FETCH_HELP` when `has_help`, else `FLEE`.

### `nearest_ally`

```gdscript
func nearest_ally(agent: StringName, nearby: StringName[], exclude: StringName = &"") -> StringName
```

The nearest ally of `agent` in `nearby` within `BustleConflictConfig.help_radius`, not in a conflict of its own, or empty. An ally regards `agent` as friendly, or shares its group without regarding it as hostile.

### `fill_inputs`

```gdscript
func fill_inputs(agent: StringName, inputs: Dictionary[StringName, float]) -> void
```

Writes `agent`'s stance into `inputs`: 1 for its stance and 0 for the others, or no `threat.*` stance inputs at all when it's in no conflict.

### `call_help`

```gdscript
func call_help(helper: StringName, agent: StringName) -> bool
```

`helper` answers `agent`'s call: it fights `agent`'s threat, and `agent` is out of the conflict. False when `agent` has no threat or `helper` is busy.

### `is_lethal`

```gdscript
func is_lethal(attacker: StringName, victim: StringName, now: int) -> bool
```

Whether `attacker`'s fight with `victim` at minute `now` is lethal: a seeded roll against `BustleConflictConfig.lethal_chance`, the same every time.

### `filter_damage`

```gdscript
func filter_damage(damage: float, health: float, lethal: bool) -> float
```

`damage` to a victim with `health`, as a fight should deal it: unchanged when `lethal`, else cut so the victim keeps at least `BustleConflictConfig.scuffle_floor`. Never negative.

### `finish`

```gdscript
func finish(agent: StringName, now: int, lethal: bool) -> void
```

Ends `agent`'s fight at minute `now` from the combat port's `BustleCombatPort.outcome()`: emits `assaulted`, and `killed` when the target died, then clears the conflict and disengages.

### `clear`

```gdscript
func clear(agent: StringName) -> void
```

Ends `agent`'s conflict without a fight (it got away, or the host ended it).
