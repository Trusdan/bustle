# BustleSequenceRunner

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Runs one [BustleActionSequence](BustleActionSequence.md) for one agent, a step at a time, with registered [BustleActionHandler](BustleActionHandler.md)s. `wait` and `idle` are registered from the start.

- **Each tick** ticks the current step once. DONE moves on and starts the next step (ticked from the next tick on); the last step DONE makes the sequence SUCCEEDED. So one tick does at most one handler tick and one start: there are no loops within a tick. - **A failed step** is cleaned up (`BustleActionHandler.cancel()`, once), then its `BustleActionStep.on_fail` applies: RETRY starts it again until `attempt` passes `BustleActionStep.max_retries` (then ABORT), SKIP starts the next step, ABORT ends the sequence FAILED with `failure`. A step with no handler fails with `unknown_action`. - **`interrupt()`** cleans up the running step and keeps its place; `resume()` starts that step again from the beginning. **`cancel()`** cleans up and returns to IDLE. Both do nothing unless there is something to stop, so calling them twice is safe. - **Saving:** `export_state()` holds the status, step, attempt, failure and the step's `BustleActionContext.data`; `import_state()` (with the same sequence) restores them, so a running step carries on exactly where it was.
