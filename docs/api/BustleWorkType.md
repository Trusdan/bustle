# BustleWorkType

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

One kind of posted, one-off work, as data: who may take it (a role, a skill level, tags), how much a given agent wants it (personality and circumstances), and what it involves (place, minutes, wage). [BustleJobBoard](BustleJobBoard.md) reads it. Standing jobs are roles and schedules, not work types. Bustle ships none; the host supplies every type. The numbers are experimental defaults.

## Methods

### `is_valid`


True when it can be used: an id, finite numbers, known sliders, a non-negative skill minimum and wage, and a positive duration.

### `score`


How much `seeker` wants this work: `priority`, plus the slider and input terms. Missing sliders count as 50 and missing inputs as 0.
