# BustleTendJob

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

Inherits: `RefCounted`

The tend job, opt-in: an able agent tends someone near it who needs care. Bustle only asks; the host does the care and owns the recovery (`BustleHealthPort.care()`).
`fill_inputs()` sets the healer's `INPUT` to the urgency of its `patient_for()` (the patient's `BustleHealthPort.needs_care()`), so the `goal_def()` goal scores higher the more urgent the care. Its band is `BustleBands.PERSONAL`: a busy agent (on duty, in a need it must see to, or under an order) doesn't tend. A downed agent doesn't either: it gets no input, and the goal carries `work`, which the downed gate blocks. Orders aren't gated.
Register a [BustleTendAction](BustleTendAction.md) for `ACTION` on each healer's runner. Nothing is random and nothing is kept: the patient is chosen from the port's readings each time.

### `patient_for`


Who `healer` would tend now: of those `nearby`, not itself, the one whose `BustleHealthPort.needs_care()` is highest and above 0 (ties in id order). Empty when `healer` is downed, or nobody needs care.

### `tend`

Asks the host to have `healer` care for `patient`, and emits `tended` with its answer. False with no port, or when the host refuses.

### `goal_def`

```gdscript
static func goal_def(minutes: int = 30) -> BustleGoalDef
```

The tend goal: band `BustleBands.PERSONAL`, tags `tend` and `work`, scored by `INPUT` in a straight line, running `ACTION` and then waiting `minutes` game minutes, so care is asked for at most that often. A refused request waits the same before the goal can be chosen again.
