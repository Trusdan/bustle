# BustleDirector

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

The storyteller: it paces host-authored events ([BustleEventDef](BustleEventDef.md)) by the story's tension and fires the one the story needs most. Nothing is random: there is no seed and no deck, and the same events, inputs, locks and clock give the same timeline.
Each `update()`, an event is eligible when its preconditions hold on the host's inputs, its cooldown has passed, it isn't lock-sensitive while a quest lock is held, and the director port (`BustleDirectorPort.allows()`) agrees. Of those, the pick is the best by, in turn: 
- pacing (`need()`): events that move tension the way the story needs come first, those that leave it alone next, and those that push the wrong way last, so they still fire when nothing else can; 
- score (`BustleEventDef.score()`), highest first; 
- id. 
At most one event fires per update, and none within `BustleDirectorRules.beat_gap_minutes` of the last. Firing emits `event_fired`; what the event does is the host's.
With no events, nothing fires, and the director port is left as it is.

What the story needs at `now`: `NEED_RELIEVE` at or above the high line, `NEED_RAISE` at or below the low line, otherwise `NEED_NONE`.

### `eligible`


The eligible events at `now`, best first (see the class description). Empty within the beat gap, before the last fired event, or with invalid rules.

### `update`

```gdscript
func update(now: int, inputs: Dictionary = {}, locked: bool = false) -> StringName
```

Fires the best eligible event at `now` on the host's `inputs`, with the quest lock `locked`, and emits `event_fired`. Returns its id, or empty when none fires.

### `last_fired`

```gdscript

```

The game minute `id` last fired, or -1.

### `export_state`

```gdscript

```

Cooldowns and recent history as plain data. Tension comes from these and the inputs, so it comes back with them.

### `import_state`


Restores `export_state()`. False, changing nothing, for another version, a malformed entry, an event id the director doesn't have, or history out of order.
