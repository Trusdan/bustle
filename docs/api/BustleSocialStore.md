# BustleSocialStore

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `BustleSocialPort`

The built-in social store: a [BustleSocialPort](BustleSocialPort.md) that keeps opinions with reasons and relationship kinds, for hosts without a social engine of their own. Deeds work as in the port's default.
**Opinions** are one-way: how `a` regards `b`, from 0 to 100, is `BustleSocialPort.NEUTRAL_OPINION` plus every live opinion entry, clamped. Each entry has a value, a reason (plain data; a `deed` key when a deed caused it) and lasts a number of game days. The store's clock is `set_time()`; entries end at their minute.
**Kinds** are one-way too (`a` counts `b` a friend). Kinds a host sets (`set_kind()`) stay until it clears them. Kinds the `rules` form from repeated deeds come and go with opinion (`kind_changed`); the rules never touch a host's kinds.

## Methods

### `set_time`

```gdscript
func set_time(now: int) -> void
```

Moves the store's clock to `now` (earlier minutes are ignored): ended entries go, and every pair's rule kinds are checked again.

### `add_opinion`

```gdscript
func add_opinion(a: StringName, b: StringName, value: float, reason: Dictionary, days: float) -> bool
```

Adds an opinion entry: `a`'s view of `b` moves by `value` for `days` game days from the store's current minute, for `reason` (plain data; put the deed key under `deed` when a deed caused it). Then checks the rule kinds. False for an empty or identical pair, a value or duration that isn't finite, or a non-positive duration.
