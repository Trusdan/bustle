# BustleConversation

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

A conversation: a few turns between two agents, each turn one interaction picked by weight and recorded through `BustleSocialInteractions.interact()`. The two sides take turns to speak, the initiator first.
It runs two ways with the same results. `run()` does a whole conversation at once (for agents nobody is watching); [BustleConverseAction](BustleConverseAction.md) does one turn per tick (for agents in view). Both go through `begin()` and `step()`, which keep everything in a plain-data state, and every choice is seeded by the world seed, the pair, the start minute and the turn, never by when a tick happens.
An interaction's weight is its `BustleInteractionDef.weight`, bent by: 
- the speaker's sliders (`BustleInteractionDef.slider_weights`); 
- the speaker's modifiers: `conversation.<id>.weight`, which traits set; 
- the speaker's opinion of the listener: a high one makes positive interactions likelier and negative ones rarer (`opinion_weight`); 
- the speaker's mood: below 50, `curt` interactions grow likelier (`curt_mood_scale`). 
A low mood also lowers the chance of starting at all (`start_mood_scale`), and a recipient can turn a start away (`accepts`).

### `curt_mood_scale`

```gdscript

```

How much a low mood raises the weight of `curt` interactions: at mood 0 it is multiplied by `1 + curt_mood_scale`.

### `opinion_weight`

```gdscript
var opinion_weight: float = 1.0
```

How much opinion bends weights: a positive interaction's weight is multiplied by `1 + opinion_weight × (opinion − 50) / 50`, a negative one's by `1 − ...` (never below 0).

True when `state` has no turns left.

### `step`

```gdscript
func step(state: Dictionary) -> Dictionary
```

Takes `state`'s next turn at `next_minute()` and moves the state on. Returns the turn's `BustleSocialInteractions.interact()` result with its `turn` number, or `{ok: false, reason}`: `finished`, or `nothing_to_say` (no interaction has any weight, which also ends the conversation).

### `run`

```gdscript
func run(initiator: StringName, recipient: StringName, now: int, opener: StringName = &"", place: StringName = &"") -> Dictionary
```

A whole conversation at once: `wants_to_start()`, then every turn. Returns `{ok: true, turns}` with each turn's result, or `{ok: false, reason}` (`declined`, `turned_away` or `no_pair`).

### `weights`

```gdscript
func weights(speaker: StringName, listener: StringName) -> Dictionary[StringName, float]
```

Each interaction's weight for `speaker` talking to `listener` (see the class description), by id, in `interactions` order. Invalid interactions are left out.

### `pick`

```gdscript
func pick(speaker: StringName, listener: StringName, roll: float) -> BustleInteractionDef
```

The interaction `speaker` picks for `listener` with `roll` (0 to 1), by `weights()`. Null when none has any weight.
