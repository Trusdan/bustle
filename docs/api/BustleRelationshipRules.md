# BustleRelationshipRules

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

When repeated deeds make one agent count another a friend or a rival, as data. A kind forms when the opinion reaches its level and enough deeds of the right sign (opinion entries with a deed in their reason) fall inside the window; it lapses only once the opinion crosses back past its release level, so it doesn't flicker. These are starting numbers, not tuning.
