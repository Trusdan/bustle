# BustleClockPort

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

The game clock, in whole game minutes. A host extends this and overrides `now_minutes()` and `day_key()` to read its own clock. The standalone default keeps its own minute count, starting at 0 and moved on with `advance()`; a day is `MINUTES_PER_DAY` minutes, so minute 1439 is in day 0 and minute 1440 starts day 1.
