# BustleChoiceKeeper

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Hysteresis around [BustleUtilityScorer](BustleUtilityScorer.md): it remembers an agent's current choice so the agent doesn't flicker between near-equal goals, and keeps failed goals out for a while.

Each `choose()`: 1. Candidates whose goal is cooling down after a failure are made ineligible. 2. If the current choice is still eligible, its selection score gets `momentum` (×1.15). Eligibility itself uses the raw score, so momentum can't keep a goal that fell below its minimum. 3. A candidate in a strictly higher band than the current choice always wins (it interrupts). 4. Otherwise, during the current goal's `BustleGoalDef.min_commit_minutes` it is kept. 5. After that, it is kept while it is inside the pick window (no draw); if it falls out, the scorer picks from the window as usual. A current choice that is no longer eligible is dropped at once.
