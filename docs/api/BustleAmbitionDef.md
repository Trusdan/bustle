# BustleAmbitionDef

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

One ambition template, as data: who it suits (personality and circumstances), when it's done, and when it can no longer happen. [BustleAmbitions](BustleAmbitions.md) reads it. Every circumstance, progress input and fact is a name the host fills each update, so a template refers to no particular person, place or system.

### `moot_facts`


Facts that make it impossible for good (its target is dead or gone, a role lost for good). Any one ends an active ambition as moot.

### `boosts`


Goal id → how much it multiplies that goal's score while the ambition is active (see `BustleAmbitions.boost()`). Boosts never change a band.

### `target_input`

```gdscript

```

The input naming the person the ambition is about (for example `court_target`). With one, only candidates whose option is that person are boosted. Empty: no target.

### `next`


The template to take next after it's completed, when that one is eligible and enabled. Empty: score the library again.

True when it can be used: an id, known sliders with finite weights and minimums, a finite target, boosts that are finite and not negative, and some way to complete (a progress line or a done fact).

### `is_done`


True when `inputs` say it's done: `done_fact` is true, or `progress_input` has reached `target` and every `done_facts` is true.
