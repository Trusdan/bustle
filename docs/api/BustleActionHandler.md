**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

The code behind one action id. Subclasses override all three methods. A handler keeps no state of its own: everything about a step lives in `BustleActionContext.data`.

The runner calls `start()` once per attempt, then `tick()` each tick until it returns DONE or FAILED. It calls `cancel()` exactly once for an attempt that started and didn't finish DONE (it failed, or was interrupted or cancelled), to release what the attempt held.
