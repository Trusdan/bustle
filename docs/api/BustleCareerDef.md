Inherits: `Resource`

A career track, as data: the ranks of one standing job. A career is the job itself, held as a role with a routine ([BustleRoleSchedules](BustleRoleSchedules.md)); the track adds ranks, a wage per rank and a skill minimum per rank. Its career block is the routine's block for `activity`: the agent works it off site when `off_site` is set. Bustle ships none; the host supplies every track.
