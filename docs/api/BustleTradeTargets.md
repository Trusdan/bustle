# BustleTradeTargets

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Which skill the `learn_trade` ambition is about, from the installed skills: fills the inputs [BustleAmbitions](BustleAmbitions.md) reads for it. Call `fill()` before `BustleAmbitions.update()`, like [BustleAmbitionTargets](BustleAmbitionTargets.md).
**Installed skills.** Only skills the skill port knows count: with [BustleSkills](BustleSkills.md) as the port, its `BustleSkills.skill_ids()`. With any other port (the default, where everyone's level is 0) no skill is installed, so `has_trade_target` stays false and the template is never assigned. 
**The line.** A skill qualifies while it's installed and the agent's level in it is below the `learn_trade` template's `BustleAmbitionDef.target` (5 by default). With no such template in `config`, none does. 
**Which skill.** `trade_skill` when the host already set it in the inputs (a pin); else, while `learn_trade` is active, the skill it's about, for as long as it's installed; else the agent's first passion (`BustleSkills.passions_of()`) that qualifies, or the qualifying skill with the lowest level, ties by id. Nothing is random. 
**Inputs.** `has_trade_target` (that skill qualifies), `trade_skill`, `skill_level` (the agent's level in it) and `trade_skill_gone` (the active ambition's skill is no longer installed, which ends it moot; the next `fill()` then picks another skill). No job, teacher or way to practise is required: practice is the host's, reported as XP to [BustleSkills](BustleSkills.md).
