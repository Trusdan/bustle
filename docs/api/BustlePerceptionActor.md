# BustlePerceptionActor

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

One actor in a [BustlePerceptionWorld](BustlePerceptionWorld.md): what others can sense of it and, if it has a `profile`, how it senses them. The host (or a perception component) keeps the fields up to date; the world reads them when it ticks. Any actor can perceive any actor.
