One story event, as host data: when it may fire, how it moves tension, how often, and whether a quest lock holds it back. The host decides what the event does when [BustleDirector](BustleDirector.md) fires it.

### `requires`


Preconditions on the host's inputs, all of which must hold. Each is `{"input": key}` with an optional `"at_least"` and/or `"at_most"`. With neither, the input must be above 0. A missing input fails.

### `tension`


### `cooldown_minutes`
