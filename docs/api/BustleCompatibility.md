# BustleCompatibility

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

How well two agents get on by nature, from -1 (they grate) to 1 (they click). It is fixed for a pair in a world: the same for the same two ids and world seed, the same both ways round, and different in another world. It comes from a 64-bit FNV-1a hash of the seed and the two ids in sorted order. A host may blend in how close the two agents' personality sliders are.

### `of`

```gdscript
static func of(a: StringName, b: StringName, world_seed: int, a_personality: BustlePersonality = null, b_personality: BustlePersonality = null, slider_weight: float = 0.0) -> float
```

The compatibility of `a` and `b` in a world seeded `world_seed`. With `a_personality` and `b_personality` given and `slider_weight` above 0, that share comes from how close their sliders are (1 when equal, -1 when opposite), the rest from the hash. 0 for an empty id or an agent paired with itself.
