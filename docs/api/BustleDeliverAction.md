`deliver`: goes on with the agent's oldest errand through `BustleCrimeWatch.deliver()`. While it still has to get there, it asks the host to move the agent towards the target (`move_to`, `talk_to` and `gear` in the output, the gear being `BustleCrimeWatch.travel_gear`); Bustle names where, the host moves the body. Done once the word is delivered, forgotten, or there's nobody to reach yet.
