# BustleDebugOverlay

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Node3D`

A world overlay for developing: a label above each agent's attached body with its ring, band, goal, step, top 3 scores and need inputs (from [BustleInspector](BustleInspector.md)). Toggle `enabled` at runtime. Off, it stops processing and frees its labels, so it costs nothing. It can't be enabled in a release build (see [BustleDebug](BustleDebug.md)).
