# BustleUtilityScorer

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Scores an agent's goals and picks one. It keeps no state.

- **A goal's score** is `base_weight × Π curve(input)`. A failed precondition, or a consideration whose input is missing, malformed or not finite, makes it ineligible with a reason; a missing input is never sampled. - **An advertisement's score**, for option *o*: `need_value = Σ relief(o,n)·curve_n(p_n)·w_n − Σ adds(o,n)·curve_n(p_n + 0.2)·w_n`, then `× Π tag_mult × distance_falloff × mood_mod × expected_thought_gain`. It is signed. `p_n` is the input `need.<n>`; a need the agent doesn't have adds nothing. Needs and tags are taken in sorted order. - **A goal that uses advertisements** makes one candidate per option, scored `goal score × advertisement score`. - **Eligible** means the preconditions pass, the numbers are finite, and the raw score is above zero and at least the goal's `BustleGoalDef.min_score`. - **Choosing:** only the highest band with an eligible candidate counts. Within it, every candidate whose selection score is within `BustleScoringConfig.pick_window` of the best is in the window, and one is picked uniformly with the given random generator (no draw when only one is). With nothing eligible, the IDLE fallback is returned.

### `choose`


Picks from `candidates`: the highest eligible band, its window, then one uniformly with `rng`. The IDLE fallback when nothing is eligible.
