# BustlePerceptionProfile

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `Resource`

How one kind of observer notices a target: what it senses, how fast its [BustleDetectionMeter](BustleDetectionMeter.md) fills and empties, and when it changes state. A project supplies one `.tres` per kind of observer; the defaults here are PROPOSED tuning, not final values.

## Constants

### `AMBIENT`

```gdscript
const AMBIENT = 0
```

Sight works by the target's visibility from ambient and placed light.

### `CARRIED_LIGHT_ONLY`

```gdscript
const CARRIED_LIGHT_ONLY = 1
```

Sight works only on targets that carry a lit light of their own (`BustleSenseTarget.carries_light`). Hearing is unaffected.

## Properties

### `sees`

Notices the target by sight.

### `hears`

```gdscript

```

Notices the target by its noise.

### `sight_range`

```gdscript
var sight_range: float = 15.0
```

How far it sees, in metres.

### `sight_angle_deg`

```gdscript
var sight_angle_deg: float = 90.0
```

The full width of the inner view cone, in degrees. Sight fills at the full rate inside it.

### `peripheral_angle_deg`

```gdscript
var peripheral_angle_deg: float = 150.0
```

The full width of the outer (peripheral) cone, in degrees. Between the inner cone and this one sight fills at half the rate. At or below `sight_angle_deg` there is no peripheral band.

### `sight_light`

```gdscript
var sight_light: int = 0
```

What light its sight needs.

### `hearing_scale`

```gdscript
var hearing_scale: float = 1.0
```

Multiplies the target's noise radius before the distance check.

### `fill_rate_sight`


Fill per second from sight, at visibility 1.0 and point-blank range.

### `fill_rate_hearing`


Fill per second from hearing, at point-blank range.

### `decay_rate`

```gdscript
var decay_rate: float = 0.15
```

Loss per second while it neither sees nor hears the target.

### `suspicious_at`

```gdscript

```

The meter level (0..1) at which it becomes suspicious.

### `alert_at`

```gdscript

```

The meter level (0..1) at which it becomes alert.

### `search_time`

```gdscript
var search_time: float = 8.0
```

How long it searches with nothing new before it is unaware again, in seconds.

### `lose_track_time`

```gdscript
var lose_track_time: float = 4.0
```

How long an alert observer can neither see nor hear the target before it starts searching, in seconds.

### `perception_hz`

```gdscript
var perception_hz: float = 10.0
```

How many times per second a perceiver with this profile senses (throttling; 0 or less: every frame).
