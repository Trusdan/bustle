# BustleDetectionMeter

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

One observer's awareness of one target: a meter from 0 to 1 that sight and hearing fill and that decays when neither reaches the target, and four states driven by it.

Each tick the project calls `tick()` with the observer's position and facing and a [BustleSenseTarget](BustleSenseTarget.md). One-off sounds arrive through `hear_event()`. The numbers come from the [BustlePerceptionProfile](BustlePerceptionProfile.md).

```gdscript
UNAWARE ──level ≥ suspicious_at──▶ SUSPICIOUS ──level ≥ alert_at──▶ ALERT
▲                                   │                              │
│                          level < suspicious_at       lost for lose_track_time
│                                   ▼                              │
└──────── search_time, nothing new ── SEARCHING ◀─────────────────┘
│ level ≥ alert_at ──▶ ALERT
```

## Methods

### `tick`

```gdscript
func tick(delta: float, observer_position: Vector3, observer_forward: Vector3, target: BustleSenseTarget) -> bool
```

Advances the meter by `delta` seconds. `observer_forward` is the way the observer faces (any length). Returns true when it sensed the target this tick.

### `hear_event`

```gdscript
func hear_event(event: BustleNoiseEvent, observer_position: Vector3) -> bool
```

A one-off sound. When it reaches the observer (and the observer hears), the meter jumps to at least `BustlePerceptionProfile.suspicious_at`, the event becomes the last known position, and an unaware or searching observer becomes suspicious. Returns true when it was heard.

### `sight_rate`

```gdscript
func sight_rate(observer_position: Vector3, observer_forward: Vector3, target: BustleSenseTarget) -> float
```

Sight's fill rate per second for `target`, or 0 when it can't see it: out of range, outside both cones, no line of sight, an observer that doesn't see, or a profile that needs a carried light on a target without one.

### `sight_cone`

```gdscript
func sight_cone(observer_position: Vector3, observer_forward: Vector3, point: Vector3) -> float
```

The geometric part of sight, without light or line of sight: 1 inside the inner cone, 0.5 in the peripheral band, 0 outside both, beyond `BustlePerceptionProfile.sight_range` or for an observer that doesn't see. A host can call it first and cast its sight ray only when it is above 0.

### `light_allows`

```gdscript
func light_allows(target: BustleSenseTarget) -> bool
```

True when the profile's `BustlePerceptionProfile.sight_light` lets it see `target`: always for `BustlePerceptionProfile.SightLight.AMBIENT`, only a target carrying a light for `BustlePerceptionProfile.SightLight.CARRIED_LIGHT_ONLY`.

### `hearing_rate`

```gdscript
func hearing_rate(observer_position: Vector3, target: BustleSenseTarget) -> float
```

Hearing's fill rate per second for `target`, or 0 when its noise doesn't reach the observer (or the observer doesn't hear).
