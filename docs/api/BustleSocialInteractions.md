# BustleSocialInteractions

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Greetings and interactions between agents, on a [BustleSocialStore](BustleSocialStore.md). Every interaction goes through one pure function, `outcome()`, which gives the same answer for the same pair, minute, interaction, compatibility and moods; `interact()` then records it: a deed (the verb is the interaction's id) and, together with it, opinion entries whose reason names that deed, plus any thoughts. A greeting is an interaction with cooldowns: one per pair (either way round) and one per initiator, so agents don't greet the same person over and over, or everyone at once.

## Methods

### `outcome`

```gdscript
static func outcome(def: BustleInteractionDef, initiator: StringName, recipient: StringName, now: int, world_seed: int, compatibility: float, initiator_mood: float = -1.0, recipient_mood: float = -1.0) -> Dictionary
```

The result of `initiator` doing `def` to `recipient` at minute `now`, without recording anything: `{interaction, initiator, recipient, to_recipient,
to_initiator}`. `to_recipient` is how much the recipient's opinion of the initiator moves, `to_initiator` the other way. Moods are 0 to 100, or negative for none. The same inputs always give the same result.

### `interact`

```gdscript
func interact(def: BustleInteractionDef, initiator: StringName, recipient: StringName, now: int, place: StringName = &"", witnesses: Dictionary[] = []) -> Dictionary
```

`initiator` does `def` to `recipient` at minute `now` at `place`, seen by `witnesses`: works out the `outcome()`, records the deed and the opinion entries that name it, and gives each side its thought. Returns the outcome with `ok` and the `deed` key, or `{ok: false, reason}`.

### `greet`

```gdscript
func greet(initiator: StringName, recipient: StringName, now: int, place: StringName = &"", witnesses: Dictionary[] = []) -> Dictionary
```

`initiator` greets `recipient` (see `greeting`), unless a cooldown is running (`{ok: false, reason: cooling_down}`). Starts both cooldowns.
