# BustleSocialInteractions

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

Greetings and interactions between agents, recorded through a social port: give it the society's (`society.ports.social`), so they land wherever that port keeps them. Every interaction goes through one pure function, `outcome()`, which gives the same answer for the same pair, minute, interaction, compatibility and moods; `interact()` then records it: a deed (the verb is the interaction's id) carrying both outcomes, and any thoughts. When the port is the built-in [BustleSocialStore](BustleSocialStore.md), opinion entries whose reason names that deed are added too; any other port weighs the deed itself (a bridge to a social engine can use its magnitude). A greeting is an interaction with cooldowns: one per pair (either way round) and one per initiator, so agents don't greet the same person over and over, or everyone at once.

## Methods

### `outcome`

```gdscript
static func outcome(def: BustleInteractionDef, initiator: StringName, recipient: StringName, now: int, world_seed: int, compatibility: float, initiator_mood: float = -1.0, recipient_mood: float = -1.0) -> Dictionary
```

The result of `initiator` doing `def` to `recipient` at minute `now`, without recording anything: `{interaction, initiator, recipient, to_recipient,
to_initiator}`. `to_recipient` is how much the recipient's opinion of the initiator moves, `to_initiator` the other way. Moods are 0 to 100, or negative for none. The same inputs always give the same result.
Compatibility and each side's mood bend a value the same way: a compatible pair, or a good mood, makes a gain larger and a loss smaller (`× (1 + lift)` and `× (1 − lift)`, never below 0); an incompatible pair, or a low mood, does the reverse. The compatibility lift is `compatibility × compatibility_scale`; the mood lift is `mood_scale × (mood − 50) / 50`.

### `interact`

```gdscript
func interact(def: BustleInteractionDef, initiator: StringName, recipient: StringName, now: int, place: StringName = &"", witnesses: Dictionary[] = []) -> Dictionary
```

`initiator` does `def` to `recipient` at minute `now` at `place`, seen by `witnesses`: works out the `outcome()`, records the deed through the port with `to_recipient` as its magnitude and `to_initiator` as its return magnitude, adds the opinion entries that name it when the port is a [BustleSocialStore](BustleSocialStore.md), and gives each side its thought. Returns the outcome with `ok` and the `deed` key, or `{ok: false, reason}`.
