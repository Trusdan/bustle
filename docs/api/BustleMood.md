# BustleMood

Generated by `tools/gen_api_docs.sh` from the `##` doc comments. Do not edit by hand.

**Experimental:** this API may change before 1.0.

Inherits: `RefCounted`

One agent's mood and thoughts. Mood heads for its target, which is the baseline plus every active thought's value (each repeat of a thought counting `BustleThoughtDef.stack_mult` of the one before, times the `thought.tag.<tag>` modifiers), clamped to the config's range. It moves at the config's rise or fall rate per game hour, times the agent's volatility, and stands still while the agent sleeps.
`advance_to()` is closed-form: it splits the time only where a thought expires, so an OFF_SCREEN agent's day costs one step per expiry. Every thought keeps its reason (`reasons()`). The dominant emotion is the emotion with the largest total of absolute thought values; on a tie the current one stays.

### `add_thought`

```gdscript
func add_thought(def: BustleThoughtDef, details: Dictionary = {}) -> bool
```

Adds a timed thought from `def` now, with `details` added to its reason. Past its stack limit the oldest of the same id goes. False for an invalid def or a held one (duration 0).

### `set_held`

```gdscript
func set_held(def: BustleThoughtDef, held: bool, details: Dictionary = {}) -> bool
```

Holds or drops a thought that lasts while its condition holds (duration 0). Holding one that is already held only updates its reason. False for an invalid def or a timed one.

### `sync_need_thoughts`

```gdscript
func sync_need_thoughts(needs: BustleNeedSet, defs: BustleThoughtDef[]) -> void
```

Holds each need thought in `defs` while its need's pressure in `needs` is at least its threshold, and drops it otherwise. Its reason names the need and the pressure.

### `advance_to`

```gdscript
func advance_to(now: int, asleep: bool = false) -> void
```

Moves to game minute `now`: thoughts that expire on the way go at their minute, and mood heads for the target between expiries, unless `asleep` (then only thoughts expire). Earlier minutes do nothing.

### `reasons`


Every active thought with its reason, strongest first: `{thought, value, emotion, reason, expires}` (expires is -1 for a held thought).
