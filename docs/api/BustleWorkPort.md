Jobs. A host extends this to give agents its jobs. The standalone default has none, unless it is given a [BustleScheduleRoster](BustleScheduleRoster.md): then an agent's job is its role that comes with a routine. Posted, one-off work is on an optional [BustleJobBoard](BustleJobBoard.md); standing jobs stay roles.
