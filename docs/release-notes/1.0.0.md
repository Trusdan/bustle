# Bustle 1.0.0

Bustle gives a place a living population: people with needs, moods, schedules, work and relationships, run headless and cheaply, for any Godot 4.7 game. 1.0.0 is the first stable release. The public API is frozen and checked in CI, bad input is answered the same way everywhere, saves from earlier releases load through versioned migrations, and the defaults and performance budgets are settled.

No port, public class, method, signal or setting was removed or renamed, and every save written by 0.8.0 or 0.9.0 still loads. Nothing is random: the same seed, inputs and clock replay the same run.

## What 1.0 promises

- **A frozen public API.** `docs/public-api/PUBLIC_API.md` lists every frozen class, port, Callable hook, signal and save-state call, and `public_api.json` holds each signature. Anything not listed, `_`-prefixed or marked `@experimental` (the debug tools and the brain's internals) is internal.
- **Deprecation before removal.** A frozen symbol is deprecated in a minor release and warns once through `BustleDeprecation`. It is removed, or its signature changed, only in a later major release (`docs/public-api/VERSIONING.md`). A check in CI fails any change that breaks these rules.
- **Supported Godot:** 4.7.x. CI tests 4.7.2-stable on Linux and Windows.

## What's new

**Stability**
- **Bad input, one policy** (`docs/errors.md`): refuse with a reason and change nothing, warn once per problem and never every tick, assert only for Bustle's own invariants. Hooks of the wrong type warn once instead of raising a script error each call.
- **Saves across versions** (`docs/saves.md`): every `import_state()` migrates an older save one step at a time and refuses a newer one. `BustleSaveFormat` gives the reason and the current version. Golden saves from 0.8.0 and 0.9.0 load in CI.
- **Defaults reviewed:** every default was confirmed (`docs/defaults-review.md`), and five config classes gain an experimental `validate()`.

**Performance**
- **Ratified budgets, gated in CI:** perception 1.0 ms average / 2.0 ms p99, FULL 1.0 / 2.0 ms, LIGHT 0.3 ms, OFF_SCREEN 0.5 ms and 2 KB of save per agent, kept in `bench/perf_budgets.gd`. CI fails a run over twice a timing budget, over the save budget, or with a stuck agent.
- **Cheaper perception and OFF_SCREEN ticking,** with the same decisions, saves and order as before.

**Crime and theft**
- `BustleCrimeWatch.prune()` lets a host archive closed crime records (experimental).
- A stolen item that is back with its owner closes its deed quietly instead of being reported.
- The witness judge falls back to the crime's personality hook, and a detection meter reads a null saved number as 0.

**Debug tools**
- **`BustleStuckWatch`** (experimental): the demo's stuck watch, now in the addon so any host can check its own population. It has hooks for travel and off-screen progress, an option that holds off-screen agents to goal and step progress, and the off-screen interval from the rings' config.

**Docs and examples**
- **Host guides:** a contract for every port with a minimal implementation (`docs/ports.md`), a walkthrough from an empty project (`docs/host-walkthrough.md`) and upgrade notes per release (`docs/upgrading.md`), all compiled and run in CI.
- **A configuration reference** (`docs/config.md`) of every setting, with its type, default, range and effect, kept in sync by CI.
- **A standalone example project,** `examples/village/`, that uses only the frozen public API.

**Packaging**
- **Each plugin folder carries its own `LICENSE` and `README.md`,** so a project that copies only the folder keeps them. Each zip therefore holds the license twice.
- **Reproducible zips:** `tools/build_release.sh` compresses with a pinned, pure-Python port of classic zlib, so the same commit gives byte-identical zips on any machine.
- **Ready for the Godot Asset Library:** a source archive limited to the addons, `LICENSE` and `README.md`, an icon, and a draft listing.

## Upgrading from 0.9.0

Most hosts need no code changes. These can still affect a 0.9.0 host:

- **New one-time warnings** for bad input that used to be ignored silently. A test suite that fails on any warning may see new ones.
- **Hooks of the wrong type** warn once and act as if unset. A broken gate (`BustleBrain.gate`, `BustleConversation.accepts`, `BustleCareers.review_hook`, `BustleRomance.ratings_policy`) now lets everything through, so check that every hook returns its documented type.
- **Refused imports keep the old state.** `BustleBrain.import_state()` and `BustleSequenceRunner.import_state()` no longer clear the brain or runner before refusing.
- **No `push_error()` for host input:** `BustleModifierSet.set_source()`, `BustleSociety.register_archetype()` and `BustleSociety.add_agent()` warn once instead, with the same return values.
- **A save from a newer version is refused** and changes nothing.
- **`BustleRolesPort` and `BustleCombatPort` declare a private `_Warn` constant.** A subclass declaring a member of that name must rename it.

`docs/upgrading.md` has the full list and a checklist, and `CHANGELOG.md` every change.
