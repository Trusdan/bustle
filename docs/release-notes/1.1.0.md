# Bustle 1.1.0

Bustle gives a place a living population: people with needs, moods, schedules, work and relationships, run headless and cheaply, for any Godot 4.7 game. 1.1.0 is the first minor release on the stable API. **Everything new is opt-in:** a 1.0.0 host that turns nothing on runs exactly as before.

There are no breaking changes. No port, public class, method, signal or setting was removed or renamed, and no frozen signature or default changed. Every save written by 0.8.0, 0.9.0 or 1.0.0 still loads. Nothing is random: the same seed, inputs and clock replay the same run.

## What's new

New API is `@experimental` (`docs/public-api/PUBLIC_API.md`): usable, but it may still change in a minor release. `docs/host-hooks.md` has a short snippet for each hook, compiled and run in CI.

**Careers**
- **Reviews by period:** a rank can name its own review length and thresholds for a period the host defines, such as a busy season (`BustleCareerRank.periods`, `BustleCareerPeriod`). `BustleCareers.update_in_period()` judges a day in a period, and `window_period()` names the period a window is judged in. `update()` is unchanged.
- **A fresh window after a break:** days off still pause the review window by default. `BustleCareers.reset_window()` lets a host start a new one after a long leave or a closed season. It keeps the rank, wage and start, and reviews nothing.

**Crime**
- **Stolen goods stay traceable after they change hands:** `BustleCrimeWatch.deed_of_item()` gives the open deed an item is from, whoever holds it now. `stolen_goods_held_by()` lists the stolen goods an agent holds, whoever stole them. Both only read.

**Aspirations**
- **An optional cap on points:** `BustleAspirationConfig.max_points` (unset by default). Earning stops at the cap, and the signals report the amount actually added.

**Health and work**
- **Three opt-in goals:**
  - seeking care, from a healer or a care place (`BustleSeekCare`);
  - resting when sick until the port says the agent is better (`BustleRestSick`);
  - fetching a healer for a downed or urgent agent (`BustleFetchHealer`), by the same movement rule as fetching help in a fight (`BustleFetchHelpAction.approach()`).

  Bustle names who and where; the host moves the bodies and gives the care.
- **Work that needs a minimum capacity:** a work type can name minimum health capacities (`BustleWorkType.min_capacities`). An agent below one isn't offered the work and can't claim it. `BustleJobBoard.refusal()` says why, and a claim held below a minimum is released (`release_unfit()`).

**Stable API**
- **Six members graduate to frozen:** `validate()` on five config classes, and `BustleCrimeWatch.prune()`.

**Saves**
- **Golden saves from 1.0.0** load in CI with the 0.8.0 and 0.9.0 ones.

**Demo and packaging**
- **A small demo room set** (`demo/environment/demo_rooms.gd`), marked as demo data.
- **An opt-in demo of the new hooks** (`House.NEW_HOOKS`, in `demo/hooks/demo_hooks.gd`). Off by default, so the demo and its hashes are unchanged.
- **An example-project zip:** `examples/village/` with the addon, ready to open and run, built reproducibly like the addon zips.

## Upgrading from 1.0.0

No changes are needed. A host class that extends one of the classes that gained members (`BustleCareers`, `BustleCrimeWatch`, `BustleJobBoard`, `BustleWorkType`, `BustleCareerRank`, `BustleAspirationConfig`, `BustleFetchHelpAction`) and declares a member with a new name must rename it. `docs/upgrading.md` has the list, and `CHANGELOG.md` every change.

## Downloads

- `bustle-1.1.0.zip`: `addons/bustle/` (with its own `LICENSE` and `README.md`) and `LICENSE`, for every project.
- `bustle-wyrd-bridge-1.1.0.zip`: `addons/bustle_wyrd/` (with its own `LICENSE` and `README.md`) and `LICENSE`, for projects that also use Wyrd (optional). The bridge is pinned to Wyrd 1.0.1.
- `bustle-example-1.1.0.zip`: the example project with the addon in it. Unzip it, open `project.godot` in Godot 4.7.x and press Play.

All three are built with `tools/build_release.sh`, which gives byte-identical zips for the same commit on any machine.
