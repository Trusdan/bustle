# modules

Optional features, each usable on its own and switched on by the host: `perception/` (senses), `needs_mood/` (mood, thoughts and mental states), `ambitions/` (long-term aims), `aspirations/` (short-lived wants and event-formed fears; see `docs/aspirations.md`), `romance/` (the courtship ladder and breakups; see `docs/romance.md`), `life_stages/` (ages, data-defined stages and the gates they put on goals and options; see `docs/life_stages.md`), `environment/` (thoughts from the room an agent is in, scored by the host; see `docs/environment.md`), `careers/` (ranks on standing jobs, with off-site career blocks, performance reviews and promotion; see `docs/careers.md`) and `skills/` (skill levels from practice, with decay, passions and work modifiers; see `docs/skills.md`).
