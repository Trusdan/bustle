# modules

Optional features, each usable on its own and switched on by the host: `perception/` (senses), `needs_mood/` (mood, thoughts and mental states), `ambitions/` (long-term aims), `aspirations/` (short-lived wants and event-formed fears; see `docs/aspirations.md`), `romance/` (the courtship ladder and breakups; see `docs/romance.md`), `life_stages/` (ages on the clock, data-defined stages, the gates they put on goals and options, and the host's birth and death hooks; see `docs/life_stages.md`), `health/` (agents react to the host's health: capacities scale work and movement, pain and sickness hold thoughts, health inputs are filled, and a downed agent picks no work and doesn't travel; no health state is kept in Bustle), `environment/` (thoughts from the room an agent is in, scored by the host; see `docs/environment.md`), `careers/` (ranks on standing jobs, with off-site career blocks, performance reviews and promotion; see `docs/careers.md`) and `skills/` (skill levels from practice, with decay, passions and work modifiers; see `docs/skills.md`).
