# modules

Optional features, each usable on its own and switched on by the host: `perception/` (senses), `needs_mood/` (mood, thoughts and mental states), `ambitions/` (long-term aims), `careers/` (ranks on standing jobs, with off-site career blocks, performance reviews and promotion; see `docs/careers.md`) and `skills/` (skill levels from practice, with decay, passions and work modifiers; see `docs/skills.md`).
