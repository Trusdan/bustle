# Bustle

A generic addon for living non-player populations in Godot: the people of a place and their daily life (needs, mood, schedules, jobs, social life and more, with each larger feature opt-in).

- **Godot:** 4.7.x.
- **License:** MIT, in [LICENSE](LICENSE) in this folder.
- **Install:** copy this folder to your project's `addons/bustle/` and enable **Bustle** under Project Settings → Plugins.
- **Docs:** https://github.com/Trusdan/bustle: the README, a host walkthrough, a guide to every port, the API reference and the changelog.

This folder depends only on Godot. Optional bridges to other addons ship as separate folders and are never needed.
