# Bustle Wyrd bridge

An optional bridge between Bustle (`addons/bustle/`, required) and the Wyrd narrative engine. With it installed on a society, Wyrd is the source of opinions, relationships and roles, and Wyrd content can ask about an agent's goal, needs and mood. It is written for exactly one Wyrd release, 1.0.1, and does nothing until it is installed on a society; a project without Wyrd still loads cleanly.

- **Godot:** 4.7.x.
- **License:** MIT, in [LICENSE](LICENSE) in this folder.
- **Install:** copy this folder to your project's `addons/bustle_wyrd/`, next to `addons/bustle/`.
- **Docs:** https://github.com/Trusdan/bustle: see `docs/wyrd-bridge.md` there.
